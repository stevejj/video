## ep08에서 가져온 공식
1. "남자 여자 ○○ 공감 100%" 시리즈 제목.
2. 처음과 끝이 이어지는 루프(첫 대사 "저녁 뭐 먹을래?" ↔ 끝 대사 "내일 저녁은 뭐 먹을래?").
3. 장면 4~6초, 대사로 꽉 채움.
4. 위쪽 상황 자막.
5. 상황에 맞춘 배경 변화(거실 소파 → 폰 화면 → 현관 → 식탁).

  - 위쪽 자막: (치킨 끊은 지 0일차).
- 6장면: 미순 "…난 안 먹어~ 여보나 먹어~" (한 번 더 깔기).
- 8장면 회수:

  - 흑백 회상 화면으로 2장면 "평생!"을 0.6초 + 띠링.
  - 미순 "치킨은 0칼로리야~"
  - 위쪽 자막: (치킨 끊은 지 40분째).
