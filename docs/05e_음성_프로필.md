## 2. 음성용 텍스트 규칙 (자막 표기와 분리)
자막에는 스토리보드 표기를 그대로 쓰고, **TTS에는 아래 규칙으로 고친 텍스트**를 준다. 두 텍스트를 `lines`에 나란히 기록한다.
1. 띄어쓰기를 표준대로 넣는다: `라면머글래?` → `라면 머글래?`
2. 느낌표·물음표는 **1개**: `끄래!!!` → `끄래!`. 강조는 태그로 한다.
3. 말줄임은 `...` 3개로 통일: `또 아침..` → `또 아침...`
4. 귀여운 발음 표기(머글래·끄래·화이띵)는 **유지**한다(캐릭터 말투). 단 모델이 못 읽는 조합이면 표준 표기로 바꾸고 기록한다.
5. 웃음·한숨·하품 같은 소리는 태그로: `[sighs]`, `[yawns]`, `[laughs]`
6. 한 대사 = 한 파일. 주고받는 대사(9-02→9-03)는 **Text to Dialogue**로 한 번에 생성해 흐름을 맞춘다(2026-09-22 실험 통과, 3.1초).

## 4. 작업 순서 (에피소드마다 동일)
1. 스토리보드에서 자막 줄을 뽑아 `lines`에 추가: 컷, 화자, 자막 표기, 음성용 텍스트, 표정 코드, 시작 시각.
2. `tools/voice_gen.py --ep ep01 --candidates 3`: 대사마다 seed 3개로 생성 → 길이가 컷 편집창 안에 들어오는 것 중 첫 번째를 채택하고 seed 기록. 이미 seed가 기록된 대사는 그 seed로 1회만 생성.
3. 청취 후 바꾸고 싶은 대사만 `--regen 컷번호`로 다른 seed 후보를 뽑는다.
4. 반복 대사("또 아침..", "07:00 알람" 등)는 **첫 에피소드 파일을 재사용**한다(`outputs/voice/library/`).
5. 조립 스크립트가 시작 시각에 배치 + loudnorm.

## 5. ep01 실측 (2026-09-22, 15줄 생성)
| 항목 | 결과 |
|---|---|
| 길이 | 감정 태그 붙은 v3는 자막 표기보다 길게 나온다. 졸림 계열 ≈ 음절당 0.35~0.45s + 0.6s, 밝은 계열 ≈ 음절당 0.25~0.35s + 0.4s (무음 제거 후) |
| 2초 컷 | "아직도 세 시..."(1.85~2.46s), "모니터 뚫어!"(2.14s)는 2초 컷에 못 들어감 → 컷 길이 2.3~3.0s로 조정(합계 62.5→64.8s). **기획에서 길이 예산을 먼저 계산해야 하는 이유** |
| seed | 같은 seed라도 매번 같지 않다(1-02 seed 1234: 2.14s → 1.70s). 포락선 상관 0.97은 "비슷함"이지 "동일"이 아님. **진짜 일관성은 채택한 mp3 파일을 보관·재사용하는 것**. seed는 재생성 시 근처를 맞추는 보조 수단 |
| 빈 응답 | 특정 텍스트+seed 조합("[annoyed] 모니터 뚫어!" seed 7·1234)은 HTTP 200에 빈 본문. 재시도해도 동일 → seed 후보를 3개 이상 두고 넘어간다 |
| 무음 | 원본에 앞뒤 0.2~0.5s 무음. -45dB 기준으로 잘라야 길이·타이밍이 맞음 |
| 음량 | loudnorm -16 LUFS 후 15줄 전부 -18~-23 dB RMS로 고르게 나옴 |
| 대화 그룹 | 9-02→9-03 Text to Dialogue 2.9s. 두 컷(2.0+1.5s)에 걸쳐 배치, 질문이 9-02 안에서 끝나고 답이 9-03 시작 직후에 옴 |
| 속도 보정 | 한도 초과분은 atempo ≤1.15(음높이 유지)로 줄임. 그 이상은 소리가 급해지므로 컷을 늘린다 |

## 6. 기획 단계에서 정해야 하는 것 (에피소드 품질 일관성의 핵심)
음성 결과를 좌우하는 변수는 5개이고, 그중 4개는 **기획에서 결정**된다. 생성 단계에서 바꿀 수 있는 건 seed뿐이다.

| 변수 | 결정 시점 | 영향 | 규칙 |
|---|---|---|---|
| 음성용 텍스트 | 기획 | 발음·길이 | 04 템플릿 §1b. 자막표출용과 분리 |
| 표정 코드 → 감정 태그 | 기획 | 톤·속도·길이 | 컷 표정과 같은 코드. 태그를 따로 고르지 않는다(표정과 소리가 어긋나는 걸 막음) |
| 유형(대화/혼잣말) | 기획 | 부리 움직임 여부, 오프셋 | 대화면 Kling 프롬프트에 부리, 혼잣말이면 부리 닫힘 |
| 컷 길이·오프셋 | 기획 | 잘림·겹침 | 길이 ≥ 예상 음성 길이 + 오프셋 + 0.3s |
| seed | 생성 | 미세한 억양 | 후보 3개 중 길이 맞는 것, 채택 파일 보관 |

**예상 음성 길이 공식(기획용, 무음 제거·배속 전 기준. 배속 1.2 후 실제 길이는 ÷1.2)**
- 졸림·째려봄·안도·걱정·생각중(04·05·10·11·12): `0.4 × 음절수 + 0.6` 초
- 활짝·놀람·감탄·화남·당황(02·03·07·08·09): `0.3 × 음절수 + 0.4` 초
- 예: "아직도 세 시"(5음절, 05) → 2.6s → 컷 최소 2.6+0.2+0.3 = 3.1s. ep01은 2.5s로 잡고 atempo로 맞췄다.

**에피소드마다 반복하는 일관성 점검**
1. 새 편 생성 전에 기준 대사 3개("또 아침...", "끄래!", "라면 머글래?")를 프로필 그대로 재생성해 ep01 파일과 포락선 상관 ≥0.9인지 확인. 낮으면 ElevenLabs 쪽 모델·목소리 변경을 의심하고 멈춘다.
2. 목소리·모델·안정성·태그 표는 이 문서에서만 바꾼다. 바꾸면 이전 편과 다르게 들린다는 걸 전제로 결정한다.
3. 반복 대사는 `outputs/voice/library/`에서 재사용(생성하지 않음).

## 8. 효과음 (ElevenLabs 효과음 생성, 2026-09-29)
- 생성: `/v1/sound-generation`, 모델 `eleven_text_to_sound_v2`, 영어 프롬프트, 원샷 0.8~3s, 환경음 6s(`loop=true`). 프롬프트·결과는 `outputs/ep01/sfx/el/generated.json`.
- **파일별 음량이 -10~-52 LUFS로 제각각**이라 배치 gain을 고정값으로 두면 안 된다. `sfx_list.json`에 파일 측정값(`measured_lufs`)과 목표(`target_lufs`)를 두고 gain = 목표 − 측정으로 계산한다.
- 목표 음량(대사 -16 LUFS 기준): 원샷 강조(알람·반짝) -18~-20, 원샷 일반(물·타자·식기·발소리·스위치) -22~-24, 환경음(역·거리·풀벌레) -30, 실내 환경음(사무실·TV) -32. 최종 믹스는 통합 약 -17.5 LUFS, 리미터 -1.4 dB.
- 배치 규칙: 환경음은 그 공간의 컷 전체를 덮고 0.3s 페이드, 원샷은 동작 시점(발소리는 걷기 시작, 스위치는 암전 직전, 알람은 컷 시작 0.2~0.3s 뒤). 같은 공간이 다시 나오면 같은 파일 재사용(사무실 오전·오후, 알람 처음·끝).
- 다음 편부터: 스토리보드 효과음 열을 그대로 `sfx_list`로 옮기고, 이미 만든 파일은 `outputs/ep01/sfx/el/`에서 재사용(같은 알람·같은 사무실 소리가 채널의 일관성).

| 효과음 출처 | CapCut 라이브러리(검증된 만화적 원샷) | ElevenLabs 생성(음량 제각각, 질감 사실적) | 만화 리액션(띠용·쿵·삐)은 라이브러리가 더 일관됨. 환경음은 생성이 괜찮음 |

**우리가 가져갈 것(다음 편 기획부터)**
1. 대사를 "자막 한 단어"에서 **짧은 문장 대화**로: 줄당 8~12음절, 상대가 1초 안에 받아치는 핑퐁 2~3회를 한 편에 넣는다. 04 템플릿 §1b의 길이 예산 공식으로 컷 길이를 같이 잡는다.
2. 말 속도 목표 5~6음절/s: v3 속도 1.05~1.1 + 배속 1.2, 말줄임표는 "뜸" 컷에만.
3. 연기는 태그보다 **텍스트 쓰기**로: 반복("왜 왜"), 추임새("아", "어"), 늘리기("으흠이구나")를 음성용 텍스트에 넣는다. 비명·한숨·웃음은 대사 파일이 아니라 **리액션 소리 파일**로 따로 두고 재사용.
4. 무대사 구간은 펀치라인 앞 1~2초의 "뜸"으로만. 정지 컷이 3개 이상 연속이면 대사나 리액션 소리를 하나 넣는다.
5. 배경음악 1곡을 전체에 깔기(저작권 안전한 것: Suno 생성 또는 무료 라이선스). 환경음은 음악 아래 -6dB 더 낮춤.
6. 만화적 리액션 원샷(띠용·쿵·반짝·삐)은 라이브러리 세트를 하나 정해 전 편 공통으로 쓴다(ElevenLabs 생성은 편마다 달라짐).

## 10. 참조 채널 실청 분석 (2026-09-30, Gemini 시청 결과 — 2편: "집가고싶다" 98s, "일희일BEE" 37s)
§9는 자막만 보고 쓴 추정이라 틀린 곳이 있었다. **"무표정 낭독"이 아니라 감정 연기**다. 아래가 실청 기준(원문: `outputs/reference/ref_*_sound.md`, Gemini의 관찰이므로 "~로 들린다" 수준).

| 축 | 참조 채널 | 우리 v6 | 조치 |
|---|---|---|---|
| 주인공 음성 | 매우 높은 피치업(+4~6반음, 칩멍크). **감정 기복 큰 더빙 연기**: 늘어지는 신음("아아아앙~"), 파안대소, 경악 숨흡입, 말끝 올림("~냥?", "몰랐지?"), 더듬기·반복 | 배속 1.2(≈+3반음), v3 태그 연기 1개, 리액션 없음 | 피치를 +4~5반음 수준으로 올리는 안 검토. **목소리 리액션(웃음·신음·숨흡입·한숨)을 대사 줄로 기획**하고 v3 태그(`[laughs]`, `[gasps]`, `[sighs]`)로 생성 |
| 조연 음성 | 사람 동료·가족은 **피치업 없는 자연스러운 보통 톤**. 주인공 초고음과의 대비가 캐릭터성 | 창수·미순 둘 다 높은 톤 | 우리는 둘 다 펭귄이라 같은 규칙 불가. 대신 창수를 미순보다 확실히 낮게(배속·피치 차등) 해 대비 확보 |
| 발음 | 피치업 속에서도 자음이 뚜렷, 대사 컴프레션 강함 | 리믹스로 또렷해짐 | 컴프레서 추가(대사 트랙에 2.5:1) |
| 효과음 | **만화 원샷을 표정 변화 프레임에 "원 포인트"**: 차임벨·뾰로롱·반짝·두둥·털썩. 5~6초에 1개. 사실적 폴리(빨대·키보드)는 동작에 | 환경음 위주, 강조음 2개(알람·반짝) | 리액션 원샷 세트 6~8종을 고정하고 표정 코드 변화마다 1개. 간격 목표 5~8초 |
| 배경음 | **상황 음악**: 상상·반전 장면에만 유명곡/감성곡을 넣고 대사 중엔 2~3으로 더킹, 펀치라인 직후 **뚝 끊거나 어두운 버전으로 교체**. 긴 편(집가고싶다)은 쓸쓸→따뜻→벅참 3단 편곡 | 없음 | 편마다 "음악이 들어가는 구간"을 기획에 표시(상상·회상·감정 전환). 전 구간 깔기보다 구간형 |
| 환경음 | **거의 없음(1~2/10)**. 스마트폰 스피커에서 대사가 100% 들리게 잡음 억제. 긴 감성편만 4/10 | 환경음 -30 LUFS, 사실상 주인공 | 코미디 편은 환경음을 -36 이하로 낮추거나 빼고, 룸톤 정도만 |
| 믹스 비율 | 대사 10 : 효과음 7 : 음악 6(대사 중 2~3) : 환경음 1 | 대사 10 : 효과음 5 : 음악 0 : 환경음 4 | 위 비율을 목표 음량표로 고정 |
| 무대사 구간 | 3~6초, **음악+목소리 리액션(웃음·빨대 소리)**으로 채움 | 환경음만 | 무대사 컷에는 리액션 소리 또는 음악 중 하나를 반드시 배치 |

**정정**: §9의 "무표정 낭독·태그 대신 텍스트" 항목은 철회. 참조는 텍스트 말버릇 + 강한 감정 연기 + 별도 리액션 소리를 **다 쓴다**. 우리가 가져갈 것은 "연기를 줄이기"가 아니라 "리액션 소리를 대사처럼 기획하기"다.

**Gemini 비용 메모**: 유튜브 URL 입력은 영상 길이만큼 토큰으로 과금(실측: 37초 4,481토큰, 98초 10,770토큰; 영상+오디오). 이번 2편은 유료 키(Tier 1)로 약 30원. **2026-09-30부터 영상 시청은 무료 등급 키(`GEMINI_API_KEY_FREE`)로만 한다** → `tools/watch_video.py`. 유료 키(`GEMINI_API_KEY`)는 이미지 생성 전용. 무료 등급 입력은 구글 제품 개선에 쓰일 수 있으므로 공개 유튜브 영상에만 사용.

## 11. 참조 채널 4편 종합 — 소리 규칙 (2026-09-30, Gemini 시청 5회: 일희일BEE×2·집가고싶다·A.S.A.P·총량의법칙)
편마다 조금씩 다른 것과 4편 전부에서 같은 것을 나눴다. 원문: `outputs/reference/ref_*_sound.md`.

**4편 공통(채널 규칙으로 확정)**
| 규칙 | 실측 |
|---|---|
| 주인공만 칩멍크(피치업+배속), 나머지 화자는 무보정 보통 톤 | 4/4편. 대비 자체가 캐릭터성 |

| 믹스 비율 | 대사 10 : 효과음 7~8 : 음악 5~7 : 환경음 1 |
| 무대사 구간은 3초 안팎 1~2개, 음악+리액션 소리로 채움 | 4/4편 |

**편마다 다른 것(장르별 선택)**
- 코미디편(일희일BEE·A.S.A.P·총량의법칙): 경쾌한 120BPM 무보컬 BGM → 반전에서 스릴러/오페라 풍으로 급전환. 사실적 효과음은 "앱 알림음(띠롱·피웅)"처럼 상황을 즉시 알리는 것만.
- 감성편(집가고싶다): 만화 효과음 대신 ASMR급 사실적 폴리, 3단 편곡, 환경음 4/10.
- A.S.A.P 특유: **겉대사(밝은 업무 톤) vs 속마음(낮고 빠른 웅얼거림)**을 같은 캐릭터 안에서 톤 분리. 우리 "혼잣말 자막"에 바로 쓸 수 있는 기법.

**우리 채널(펭귄 둘) 적용안**
1. 사람 vs 햄찌 대비를 못 쓰므로 **창수(낮게, 느리게) vs 미순(높게, 빠르게)** 대비를 배속·피치 차등으로 만든다. 예: 미순 배속 1.25, 창수 1.1.
2. 혼잣말 자막은 A.S.A.P 방식으로 **속마음 톤**(낮은 볼륨, 빠른 웅얼거림, 살짝 먹먹한 EQ)으로 생성·처리해 대화 대사와 구분.
3. 리액션 소리 10초당 1개, 만화 효과음 5~6초 간격, 구간형 BGM, 환경음 -36 LUFS 이하 (§10과 동일).
4. 기획 템플릿에 "BGM 구간(시작·끝 컷, 분위기, 전환 방식)" 칸을 추가한다.
