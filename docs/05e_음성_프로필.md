# 05e. 음성 프로필 (ElevenLabs) — 모든 에피소드 공통

목적: 어느 에피소드를 만들어도 팽창수·팽미순 목소리가 **같은 톤·같은 발음 규칙·같은 음량**으로 나오게 한다. 이 문서와 `outputs/voice_profile.json`이 기준이고, 생성 스크립트(`tools/voice_gen.py`)는 이 프로필만 읽는다.

## 1. 고정 값 (바꾸지 않는다)
| 항목 | 값 | 근거 |
|---|---|---|
| 목소리 | 팽창수 `q1dzImr8s09En2iY9uGZ`, 팽미순 `JZhjPOVB6rdotoOCacMU` (계정에 저장된 Voice Design) | 2026-09-22 샘플 청취. **웹에서 목소리를 다시 만들거나 덮어쓰지 않는다** — 바뀌면 전 에피소드와 어긋남 |
| 모델 | `eleven_v3` | v2보다 표현력·길이 안정성 좋음(v2는 "끄래!!!"를 3초로 늘림) |
| 안정성 | 0.5 (natural) | 1.0(robust)은 감정 태그 반응이 약함. 0.0(creative)은 발음이 흔들림 |
| 유사도 | 0.8 | 기본 |
| 속도 | 1.0 (짧은 대사) / 0.9 (2어절 이상 또는 졸린 대사) | C·B 샘플 비교 |
| 감정 태그 | 대사 앞에 **영어 태그 1개만** (`[excited] 끄래!`) | 태그 2개 이상은 길이·톤이 흔들림 |
| seed | 대사마다 고정, `outputs/voice_profile.json`의 `lines`에 기록 | 같은 seed = 거의 같은 소리(포락선 상관 0.97, 다른 seed는 0.48). 마음에 든 결과의 seed를 기록해두면 재생성해도 유지 |
| 후처리 | 음량 정규화 -16 LUFS(ffmpeg loudnorm), 피치 변경 **없음**(사용자 결정 전까지) | 컷마다 음량이 다르면 톤이 달라 보임 |
| 출력 | mp3 44.1kHz 128k → 조립 시 aac | |

## 2. 음성용 텍스트 규칙 (자막 표기와 분리)
자막에는 스토리보드 표기를 그대로 쓰고, **TTS에는 아래 규칙으로 고친 텍스트**를 준다. 두 텍스트를 `lines`에 나란히 기록한다.
1. 띄어쓰기를 표준대로 넣는다: `라면머글래?` → `라면 머글래?`
2. 느낌표·물음표는 **1개**: `끄래!!!` → `끄래!`. 강조는 태그로 한다.
3. 말줄임은 `...` 3개로 통일: `또 아침..` → `또 아침...`
4. 귀여운 발음 표기(머글래·끄래·화이띵)는 **유지**한다(캐릭터 말투). 단 모델이 못 읽는 조합이면 표준 표기로 바꾸고 기록한다.
5. 웃음·한숨·하품 같은 소리는 태그로: `[sighs]`, `[yawns]`, `[laughs]`
6. 한 대사 = 한 파일. 주고받는 대사(9-02→9-03)는 **Text to Dialogue**로 한 번에 생성해 흐름을 맞춘다(2026-09-22 실험 통과, 3.1초).

## 4. 작업 순서 (에피소드마다 동일)
1. 스토리보드에서 자막 줄을 뽑아 `lines`에 추가: 컷, 화자, 자막 표기, 음성용 텍스트, 표정 코드, 시작 시각.
2. `tools/voice_gen.py --ep ep01 --candidates 3`: 대사마다 seed 3개로 생성 → 길이가 컷 편집창 안에 들어오는 것 중 첫 번째를 채택하고 seed 기록. 이미 seed가 기록된 대사는 그 seed로 1회만 생성.
3. 청취 후 바꾸고 싶은 대사만 `--regen 컷번호`로 다른 seed 후보를 뽑는다.
4. 반복 대사("또 아침..", "07:00 알람" 등)는 **첫 에피소드 파일을 재사용**한다(`outputs/voice/library/`).
5. 조립 스크립트가 시작 시각에 배치 + loudnorm.
