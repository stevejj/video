## 2. 음성용 텍스트 규칙 (자막 표기와 분리)
자막에는 스토리보드 표기를 그대로 쓰고, **TTS에는 아래 규칙으로 고친 텍스트**를 준다. 두 텍스트를 `lines`에 나란히 기록한다.
1. 띄어쓰기를 표준대로 넣는다: `라면머글래?` → `라면 머글래?`
2. 느낌표·물음표는 **1개**: `끄래!!!` → `끄래!`. 강조는 태그로 한다.
3. 말줄임은 `...` 3개로 통일: `또 아침..` → `또 아침...`
4. 귀여운 발음 표기(머글래·끄래·화이띵)는 **유지**한다(캐릭터 말투). 단 모델이 못 읽는 조합이면 표준 표기로 바꾸고 기록한다.
5. 웃음·한숨·하품 같은 소리는 태그로: `[sighs]`, `[yawns]`, `[laughs]`
6. 한 대사 = 한 파일. 주고받는 대사(9-02→9-03)는 **Text to Dialogue**로 한 번에 생성해 흐름을 맞춘다(2026-09-22 실험 통과, 3.1초).

## 4. 작업 순서 (에피소드마다 동일)
1. 스토리보드에서 자막 줄을 뽑아 `lines`에 추가: 컷, 화자, 자막 표기, 음성용 텍스트, 표정 코드, 시작 시각.
2. `tools/voice_gen.py --ep ep01 --candidates 3`: 대사마다 seed 3개로 생성 → 길이가 컷 편집창 안에 들어오는 것 중 첫 번째를 채택하고 seed 기록. 이미 seed가 기록된 대사는 그 seed로 1회만 생성.
3. 청취 후 바꾸고 싶은 대사만 `--regen 컷번호`로 다른 seed 후보를 뽑는다.
4. 반복 대사("또 아침..", "07:00 알람" 등)는 **첫 에피소드 파일을 재사용**한다(`outputs/voice/library/`).
5. 조립 스크립트가 시작 시각에 배치 + loudnorm.

## 5. ep01 실측 (2026-09-22, 15줄 생성)
| 항목 | 결과 |
|---|---|
| 길이 | 감정 태그 붙은 v3는 자막 표기보다 길게 나온다. 졸림 계열 ≈ 음절당 0.35~0.45s + 0.6s, 밝은 계열 ≈ 음절당 0.25~0.35s + 0.4s (무음 제거 후) |
| 2초 컷 | "아직도 세 시..."(1.85~2.46s), "모니터 뚫어!"(2.14s)는 2초 컷에 못 들어감 → 컷 길이 2.3~3.0s로 조정(합계 62.5→64.8s). **기획에서 길이 예산을 먼저 계산해야 하는 이유** |
| seed | 같은 seed라도 매번 같지 않다(1-02 seed 1234: 2.14s → 1.70s). 포락선 상관 0.97은 "비슷함"이지 "동일"이 아님. **진짜 일관성은 채택한 mp3 파일을 보관·재사용하는 것**. seed는 재생성 시 근처를 맞추는 보조 수단 |
| 빈 응답 | 특정 텍스트+seed 조합("[annoyed] 모니터 뚫어!" seed 7·1234)은 HTTP 200에 빈 본문. 재시도해도 동일 → seed 후보를 3개 이상 두고 넘어간다 |
| 무음 | 원본에 앞뒤 0.2~0.5s 무음. -45dB 기준으로 잘라야 길이·타이밍이 맞음 |
| 음량 | loudnorm -16 LUFS 후 15줄 전부 -18~-23 dB RMS로 고르게 나옴 |
| 대화 그룹 | 9-02→9-03 Text to Dialogue 2.9s. 두 컷(2.0+1.5s)에 걸쳐 배치, 질문이 9-02 안에서 끝나고 답이 9-03 시작 직후에 옴 |
| 속도 보정 | 한도 초과분은 atempo ≤1.15(음높이 유지)로 줄임. 그 이상은 소리가 급해지므로 컷을 늘린다 |

## 6. 기획 단계에서 정해야 하는 것 (에피소드 품질 일관성의 핵심)
음성 결과를 좌우하는 변수는 5개이고, 그중 4개는 **기획에서 결정**된다. 생성 단계에서 바꿀 수 있는 건 seed뿐이다.

| 변수 | 결정 시점 | 영향 | 규칙 |
|---|---|---|---|
| 음성용 텍스트 | 기획 | 발음·길이 | 04 템플릿 §1b. 자막표출용과 분리 |
| 표정 코드 → 감정 태그 | 기획 | 톤·속도·길이 | 컷 표정과 같은 코드. 태그를 따로 고르지 않는다(표정과 소리가 어긋나는 걸 막음) |
| 유형(대화/혼잣말) | 기획 | 부리 움직임 여부, 오프셋 | 대화면 Kling 프롬프트에 부리, 혼잣말이면 부리 닫힘 |
| 컷 길이·오프셋 | 기획 | 잘림·겹침 | 길이 ≥ 예상 음성 길이 + 오프셋 + 0.3s |
| seed | 생성 | 미세한 억양 | 후보 3개 중 길이 맞는 것, 채택 파일 보관 |

**예상 음성 길이 공식(기획용, 무음 제거·배속 전 기준. 배속 1.2 후 실제 길이는 ÷1.2)**
- 졸림·째려봄·안도·걱정·생각중(04·05·10·11·12): `0.4 × 음절수 + 0.6` 초
- 활짝·놀람·감탄·화남·당황(02·03·07·08·09): `0.3 × 음절수 + 0.4` 초
- 예: "아직도 세 시"(5음절, 05) → 2.6s → 컷 최소 2.6+0.2+0.3 = 3.1s. ep01은 2.5s로 잡고 atempo로 맞췄다.

**에피소드마다 반복하는 일관성 점검**
1. 새 편 생성 전에 기준 대사 3개("또 아침...", "끄래!", "라면 머글래?")를 프로필 그대로 재생성해 ep01 파일과 포락선 상관 ≥0.9인지 확인. 낮으면 ElevenLabs 쪽 모델·목소리 변경을 의심하고 멈춘다.
2. 목소리·모델·안정성·태그 표는 이 문서에서만 바꾼다. 바꾸면 이전 편과 다르게 들린다는 걸 전제로 결정한다.
3. 반복 대사는 `outputs/voice/library/`에서 재사용(생성하지 않음).
