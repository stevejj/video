# ep14 기획안 — 김장 수술실: "나는 실패하지 않습니다" (2026-10-22)

> 사용자: 지독한 미순 패러디. 드라마 닥터X에서 김지원이 하는 "나는 실패하지 않습니다" 대사를 미순·창수 상황극으로.
> - 원본 장면을 그대로 따라 하는 게 아니라 대사 한 줄만 빌린 오리지널 상황극.
> - 미순 = 집도의, 창수 = 간호사(조수). 미순은 진짜로 실패하지 않는데, 대가는 창수가 치른다.

## 혼잣말 처리 (3, 10번 · 기존 규칙 그대로)
- 자막: 괄호로 감싸고 창수 색(블루).
- 영상: 부리 닫힘.
- 음성: 보이스오버. asetrate 1.10 + 동굴 리버브(`assets/ir/cave_big.wav`) + 음량 -6 (`05e_음성_프로필.md`).

## 4번 땀 닦기 — 실수 없이 표현하기
| 항목 | 정한 것 | 이유 |
|---|---|---|
| 화면 | 가슴 위 투샷. 창수 왼쪽, 미순 오른쪽(기준 투샷) | 몸 전체가 나오면 동작이 커짐 |
| 미순 | 정면 응시, 꼼짝 안 함. 기본 표정, 시선은 배추 쪽 | 수술 집중 느낌이 웃음 포인트. 얼굴이 안 움직이니 왜곡도 줄어듦 |

| 소품 | 접은 흰 거즈 1장을 **양 날개 끝 사이에 끼워** 듦 | 한쪽 날개로 쥐면 손가락이 생김(바이블 1.4) |

| 프레임 | 시작 = 거즈가 이마 앞 약간 떨어짐, 끝 = 거즈가 이마에 닿음 | 이동 동작은 시작+끝 필수(Q31) |
| 실패 시 (0원) | 정지 이미지 2장(닿기 전/닿음) 빠른 컷 + "톡톡" 효과음 | 크레딧 재시도 컷당 1회 |

## 제작 주의
- **2번 고무장갑 없음.** 장갑은 손가락을 만들어 금지 항목에 걸림. 맨 날개로 수술 전 포즈.
- **9번 맛보기:** 부리로 먹는 동작은 왜곡 위험. 김치를 부리 앞까지 가져가는 컷 → 다음 컷 부리 닫고 눈 감고 우물우물 + "오…. 마싯다…".
- **10번:** 넓은 정지 컷(배추 산). 줌아웃은 카메라 기법 금지(Q39)라 편집으로 확대 컷 → 전체 컷 전환.
- 몸짓은 작게, 긴장감은 편집(확대·흔들림·빠른 컷)으로(ep13 몸짓 규칙).
