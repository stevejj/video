## 2. 왜 되는가 (규칙으로 뽑은 것)
1. **한 샷, 한 캐릭터, 한 장소, 한 동작.** 설명 0. 보는 사람이 캡션 한 줄로 상황을 받고 몸짓만 본다.
2. **같은 동작의 2단 가속**: 한 손 → 두 손. 두 번째가 첫 번째보다 크고 소리도 크다. 3단은 없다(7초).
3. **루프 설계**: 끝(폭발) 직후 처음(얌전)으로 돌아가는 게 "again today"의 개그. 첫 프레임과 끝 프레임의 자세가 같아야 한다.
4. **글자 0.** 화면에 글자가 없어서 캐릭터 표정·몸짓에 눈이 간다. 전제는 캡션 "POV:"가 맡는다.
5. **소리 = 동작 강조만.** 음악·목소리 없이 환경음(타자) + 타격음 2개. 타격음 크기 차이가 가속을 만든다.
6. **의상·소품이 캐릭터 설정을 대신 말한다**(원피스·사원증·서류 더미).

## 4. ep03 후보 (팽창수·팽미순, 대사 없음, 7~8s, 2단 가속, 루프)
**A. 과자 (추천)** — 창수가 소파에 앉아 과자를 먹는다. 옆에 미순이 이불 덮고 누워 TV만 본다. 1단: 미순 날개가 이불 밑에서 나와 창수 손의 과자 한 개를 가져간다(창수 멈칫). 2단: 날개가 봉지째 가져간다(창수 빈손, 눈 깜빡). 끝 = 창수 빈손으로 TV. 루프하면 다시 과자 먹는 창수.
캡션: "우리집 미순이는 TV만 봐요🐧" / 소리: TV 환경음 + 바스락(작게) + 봉지 홱(크게).
**B. 못 일어나게** — 미순이 창수 무릎 베고 누워 있다. 창수가 일어나려 하면(1단: 반쯤) 미순 날개가 눌러 앉힌다. 2단: 더 크게 일어나려다 더 세게 눌려 쿵. 끝 = 처음 자세. 캡션: "우리집 미순이는 베개를 안 놔줘요🐧".
**C. 리모컨** — 미순이 누운 채 이불 위를 더듬는다. 리모컨은 바로 옆. 1단: 창수가 와서 10cm 옮겨 준다. 2단: 다시 더듬자 창수가 리모컨을 날개에 쥐여 주고 간다. 캡션: "우리집 미순이는 손을 안 뻗어요🐧". (ep02와 소재 겹침 → 보류)

A를 추천하는 이유: 창수 리액션이 "멈칫 → 빈손 깜빡" 두 단계로 표정 코드 01 안에서 해결되고, 이불 밑에서 날개만 나오는 그림이 Kling에서 안정적(미순 몸은 고정). 봉지째 가져가는 2단이 소리(홱)로 가속을 만든다.
