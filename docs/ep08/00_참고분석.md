## 1. 형식
- 43s, 30/40/30 띠(위 검은 띠 제목 "남자 여자 / 준비시간 공감 100%", 아래 채널명).

- 경쾌한 코믹 피아노 BGM이 끝까지 깔림. 효과음은 놀람·드라이기·분노 강조·샤워 물소리·변신 완료.

## 3. 왜 공감되나 (F3)
1. **누구나 아는 남녀 차이**: 1시간 동안 머리·옷·가방·구두로 고민하는 아내 vs 5분 컷 올인원 샤워 남편.
2. **전세 역전 = 펀치라인**: 내내 재촉하던 아내가 마지막엔 구두도 못 골랐고, 빈둥대던 남편이 "아직도 멀었어?".
3. 괄호 상황 자막(준비시간 30분 남음 → 나가기 5분 전)이 시간 압박을 숫자로 보여 줌.
4. "입을 옷이 없네"(옷장 지분 90%) 같은 디테일.
