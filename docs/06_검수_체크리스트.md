# 06. 검수 체크리스트 (v0.1)

> 이미지 단계와 영상 단계를 나눈다. 하나라도 ❌면 채택하지 않는다. 재생성은 샷당 상한(Q30 미정, 기본 3회)까지.

## A. 프레임(이미지) 검수 — 시작·끝 프레임 각각

### A1. 캐릭터 (01 바이블 3장)
- [ ] 팽창수: 털뭉치 있음 / 볼터치 없음 / 머리 진한 슬레이트 그레이
- [ ] 팽미순: 털뭉치 없음 / 분홍 볼터치 / 머리 밝은 은회색
- [ ] 눈: 크기·간격·하이라이트 위치 유지, 흰자 없음(Q6b 예외 표정 제외)
- [ ] 부리: 코랄 오렌지, 형태 유지, 개폐 상태가 샷리스트와 일치
- [ ] 없음: 눈썹, 속눈썹, 이빨, 혀, 손가락, 팔, 목, 옷, 액세서리
- [ ] 2등신 비율, 플러시 털 질감(**털 결이 보여야 함. 매끈·플라스틱·비닐이면 불합격**, R17)
- [ ] **발**: 매끈한 회색, 발가락 요철 3개, 발바닥 패드·발톱 없음 (R10)
- [ ] **날개 끝**: 짧고 둥긂, 손가락 없음 (R10)
- [ ] **털뭉치**(팽창수): 정수리 중앙, 모든 각도에서 보임 (R10)
- [ ] 표정이 지정된 표정 시트 ID와 일치

### A2. 장면·연속성
- [ ] 공간 기준 컷과 배경 일치(벽, 창, 가구 위치)
- [ ] 고정 소품표에 없는 소품 없음
- [ ] 문·서랍·조명·창 상태가 샷리스트와 일치
- [ ] 시간대(창밖 밝기)와 실내 조명 일치
- [ ] 스케일: 캐릭터 옆에 기준 물체가 있고, 비율이 스케일표와 일치 (R9). 작은 소품은 신체 부위 대비 문장으로 지정됐는지(R9 보강)
- [ ] 프레임 점유율이 지정값과 일치(참조 이미지의 70% 프레이밍을 따라 하지 않았는지) (R9)
- [ ] 좌/우 날개 점유가 샷리스트와 일치
- [ ] 끝 프레임은 시작 프레임과 구도·조명·배경 동일, 캐릭터 자세만 다름

### A3. 구도(02a)
- [ ] 9:16, 1080x1920 이상
- [ ] 얼굴·핵심 동작이 높이 12~72%, 폭 좌측 88% 안
- [ ] 컷 크기가 지정(전체/중간/확대/둘)과 일치
- [ ] 눈높이

### A4. 상식·연출(03)
- [ ] R1 문 방향·도어락 / R2 날개 점유 / R4 물리적 가능성
- [ ] 대화 컷: 시선 방향(창수 우, 미순 좌), 몸 3/4 회전, 화자만 부리 움직임 (R12)
- [ ] 시간 경과 컷: 시간대 조명이 시간표와 일치, 표지 2개 이상, 경과 후 인벤토리 재설정 (R13)

## B. 클립(영상) 검수 — 첫·중간·끝 3지점 + 전체 재생

### B1. 캐릭터 유지
- [ ] A1 항목이 3지점 모두에서 유지
- [ ] 부리 열림·닫힘이 지시대로(닫힘 지시 시 열리는 프레임 없음, 말하는 클립은 미세 움직임만, 한 클립에 부리 움직이는 캐릭터 최대 1명)
- [ ] 클립 안에서 조명·시간대 변화 없음 (R13)
- [ ] 손가락·팔·추가 신체 등장 없음

### B2. 동작
- [ ] 끝 프레임 상태에 실제로 도달(위치·자세)
- [ ] 제자리 걸음·발 미끄러짐 없음
- [ ] 순간이동·잘림 없음
- [ ] 든 물건이 사라지거나 변형되지 않음
- [ ] 동작 속도가 지시(천천히/보통)와 일치

### B3. 장면
- [ ] 배경·소품이 클립 내내 고정(드리프트 없음)
- [ ] 조명 깜빡임 없음
- [ ] 카메라 완전 고정(팬·줌·흔들림 없음)
- [ ] 임의 컷·샷 전환 없음(멀티샷 꺼짐 확인)
- [ ] 다른 인물·펭귄 등장 없음

### B4. 연결
- [ ] 체이닝 컷: 끝 프레임이 다음 컷 시작 프레임과 동일
- [ ] 좌우 위치 관계 유지(창수 좌·미순 우)

## C. 기록
- 각 컷의 검수 결과와 재생성 횟수, 실패 원인(00b B6 유형)을 샷리스트 옆 열에 기록한다.
- 같은 원인이 3회 이상 반복되면 규칙집 또는 프롬프트 템플릿을 고친다.
