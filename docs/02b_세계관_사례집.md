# 02b. 세계관 사례집 (초안 v0.1)

> 목적: 주제가 무엇이든 부딪힐 "이 세계에서 이건 어떻게 되는가"를 미리 정한다.
> 형식: 사례 → 왜 문제인가 → 기본안(내 제안) → 상태. 사용자가 사례를 추가하면 같은 형식으로 붙인다.
> 확정된 항목은 `02_공간_바이블.md` 0장(세계관)으로 옮긴다.

확정된 전제: 펭귄 체구 기준의 평범한 한국 공간, 등장 캐릭터는 둘뿐, 다른 펭귄 없음.

**사람 규칙(확정, 2026-09-16 수정)**: 사람은 필요하면 등장시킨다. 단 **얼굴이 나오지 않는 선**에서, 시청자가 "사람이구나" 인식할 정도로만. 표현하기 쉬운 방식을 쓴다.
- 허용 방식: 뒷모습, 어깨 아래만(프레임 상단에서 잘림), 멀리 흐리게, 실루엣, 손·팔만(단 캐릭터와 물건 주고받기는 인서트로 분리).
- 크기: 펭귄과 **같은 키**(펭귄 세계 스케일 유지. 사람이 크면 캐릭터가 인형처럼 보임).
- 대사 없음. 표정 없음(얼굴이 없으므로). 이름 없음.
- 한 컷에 최대 2명, 3초 이내. 캐릭터와 직접 상호작용은 인서트(손이 상자를 건넴 등)로만.
- 프롬프트 문구: `a human figure the same height as the character, seen from behind / cropped above the shoulders, face never visible, plain clothing, no text on clothing`

## A. 다른 존재 (사람·펭귄이 없는데 세상이 돌아가야 함)

| # | 사례 | 왜 문제인가 | 기본안 | 상태 |
|---|---|---|---|---|
| W1 | 버스·택시·지하철 | 운전자·승객이 필요 | 기본은 **타는 장면을 안 만든다**(기다리기, 내린 뒤 걷기). 꼭 필요하면 운전자·승객은 얼굴 없는 사람(뒷모습·어깨 아래)으로 허용. 차량 외부 컷 우선 | 확정(사람 규칙 적용) |
| W2 | 자가용 | 창수가 운전하면 가능. 날개로 핸들? | 차 소유 여부 결정 필요. 있다면 운전 컷은 **외부 컷(차가 지나감)** + 내부는 조수석 쪽 얼굴 확대만. 핸들 잡는 손 컷 없음 | 결정 필요 |
| W3 | 편의점·카페·식당 점원 | 응대할 사람 | 무인(키오스크) 우선. 점원이 필요하면 카운터 뒤 **어깨 아래만 보이는 사람**. 물건 건네는 건 손 인서트 | 확정(사람 규칙 적용) |
| W4 | 배달·택배 기사 | 문 앞에 누가 와야 함 | 기본은 "문 앞에 놓인 상태"부터. 기사가 필요하면 뒷모습으로 멀어지는 컷 정도 | 확정(사람 규칙 적용) |
| W5 | 회사 동료·상사 | 회사 편이면 생김 | 동료는 문자·전화(자막)가 기본. 화면에 필요하면 **얼굴 없는 사람**(뒷모습, 어깨 아래)으로 옆자리·복도에 배치. 대사 없음. 회의 장면은 뒷모습들만 | 확정(사람 규칙 적용) |
| W6 | 가족·친척·친구 | 명절·경조사 주제에서 생김 | 등장 없음. 전화·문자로만. 명절은 "둘이서 보내는" 설정 | 제안 |
| W7 | 화면 밖 사람의 목소리·문자 | | 허용. 문자는 오버레이, 통화는 자막(회색). 화면에 나올 땐 사람 규칙(얼굴 없음) | 확정 |
| W8 | 반려동물 | 펭귄이 개를 키우면 이상? | 반려동물 없음. 곤충·새·소동물은 **자연 존재**로 허용(사마귀 사례). 말하는 동물 없음 | 제안 |
| W9 | 길거리 행인·지나가는 차 | 도시가 텅 비면 이상 | 행인은 멀리·뒷모습으로 소수 허용(한 컷 2명). 움직이는 차는 없음(운전자 문제 + 영상 왜곡), 주차된 차 허용. 생활감은 가게 불·빨래 같은 흔적으로 | 확정(사람 규칙 적용) |

## B. 펭귄 신체로 할 수 없는 것

| # | 사례 | 왜 문제인가 | 기본안 | 상태 |
|---|---|---|---|---|
| W10 | 먹기 | 부리+젓가락 = 왜곡 | **먹는 제스처(음식을 입으로 가져가기)는 없음.** 대신 (1) 프레임에 무슨 음식인지 보이게 + (2) 부리를 **오물오물 작게** 움직이는 클립. 시청자는 "먹고 있구나"로 이해. 젓가락·숟가락은 날개에 끼운 정지 상태까지만. 음식 양 변화(가득→빈 그릇)는 컷 사이에서 | 확정(사용자) |
| W11 | 양치·세수·샤워 | 이빨 없음. 물+털 질감 왜곡 | 양치 없음. 세수는 세면대 앞에 선 컷 + 수건으로 얼굴 닦는 컷. 샤워는 문 닫힌 욕실 + 물소리(효과음) | 제안 |
| W12 | 타이핑·글쓰기·휴대폰 터치 | 손가락 없음 | 휴대폰은 한 날개로 쥐고 **화면 보는 컷**만(터치 동작 없음). 타이핑은 키보드 위 날개 정지 컷 + 타자 소리(효과음). 글쓰기 없음 | 제안 |
| W13 | 요리 | 칼질, 젓기 = 미세 조작 | 냄비 앞에 선 컷, 국자를 날개에 끼운 정지 컷, 완성 요리 인서트. 칼질 없음 | 제안 |
| W14 | 문 열기 외의 조작(스위치, 리모컨, 버튼) | 날개 끝으로 누르기 | **날개 끝으로 누르기 허용**(엘리베이터 버튼, 조명 스위치, 리모컨). 단 인서트 컷으로 분리(R3), 프롬프트에 "presses with the rounded tip of the wing" | 제안 |
| W15 | 펭귄 생물 특성 | | **외형일 뿐.** 사람처럼 더위·추위 느끼고 사람 음식 먹음. 펭귄 개그 없음 | 확정(사용자) |
| W16 | 뛰기·점프·계단 | 다리 왜곡 | 뛰기·점프 없음. 계단은 오르는 중 컷 없이 **아래 컷 → 위 컷**. 급할 땐 뒤뚱 빠른 걸음 + 효과음 | 제안 |

## C. 물건·정보·글자

| # | 사례 | 왜 문제인가 | 기본안 | 상태 |
|---|---|---|---|---|
| W17 | 간판·표지판·책·포장지의 글자 | AI 글자는 깨짐 | 생성 이미지의 글자는 **전부 오버레이 또는 흐림**. 프롬프트에 `no readable text`. 필요한 글자(가게 이름, 안내판)는 편집에서 얹음 | 제안 |
| W18 | 휴대폰·TV·PC 화면 | 화면 내용이 매번 달라짐 | 화면은 **빈 밝은 화면**으로 생성, 내용은 오버레이. 화면 인서트는 정지 컷 | 제안 |
| W19 | 돈·카드·영수증 | 숫자 깨짐, 시대감 | 현금 없음. 카드·휴대폰 결제만. 영수증 숫자는 오버레이 | 제안 |
| W20 | 옷·가방 없이 "외출 준비"를 어떻게 보여주나 | 소품 원칙 없음 | 외출 준비 신호는 **현관에서 신발 신기 없음(펭귄 발)** → 대신 "현관문 앞에 서기 + 열쇠·휴대폰 드는 인서트". 가방은 소품 3단계 테스트 통과 시에만 | 결정 필요 |
