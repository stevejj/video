## 2. 왜 이해되나 (F3)
1. **누구나 아는 형식**: 댄스 배틀 = 번갈아 추기. 차례 바뀔 때 비트가 끊겨서 설명 없이 읽힘.
2. **한 명은 뒷모습, 한 명은 정면**: 관객 자리에서 보는 구도라 "대결"이 바로 보임.
3. **반전 엔딩**: 자신만만하던 쪽(뒷짐)이 마지막에 카메라 보며 놀라 박수 = "졌다". 이 한 컷이 웃음 포인트.
4. 짧고(15s) 끝이 처음과 이어짐 → 반복 재생.

## 3. 우리 버전으로 옮기기
- 삼색이(뒷짐, 자신만만) = **창수**(ep05처럼 뒷모습, 꼭지 깃털), 회색이 = **미순**(정면, 볼터치).
- 고양이의 발차기·다리 들기 → 펭귄은 다리가 짧음: **좌우 뒤뚱 스텝, 제자리 한 바퀴 돌기, 날개 퍼덕, 엉덩이 흔들기, 고개 까딱**으로 바꿈(02c M16 몸 늘이기 금지).
- 엔딩 웃음 포인트(뒷모습이던 창수가 돌아서서 놀란 눈 + 박수)는 그대로 가져감.
- 장소: 참고는 실내 의자 위지만, 우리 버전은 **길거리 배틀**(사용자 선택, 2026-10-19).
