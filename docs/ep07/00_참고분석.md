## 2. 왜 이해되나 (F3)
1. **어른 술자리 흉내**: 포장마차·잔·인생 한탄은 누구나 아는 "아저씨 술자리". 그걸 아기가 분유로 하니까 웃김(어울리지 않는 주인공 + 익숙한 상황).
2. **대사가 진지할수록 웃김**: "인생 뭐 있냐" 같은 철학을 아주 진지한 표정으로.
3. **술자리 의식 순서**가 그대로: 한탄 → "마지막 한 잔 콜" → 짠 → 원샷 → "캬~" → "이모 한 병 더!"(마지막이라더니 또 시킴) = 반전 엔딩.
4. 와이드(대화)와 클로즈업(짠·캬)을 번갈아 리듬을 만듦.

## 3. 우리 버전으로 옮기기 (사용자 지시 2026-10-19)
- 배경: **포장마차**. 아기 둘 → **창수·미순**.
- 젖병 → **맥주잔**. 소품 연속성표(F8)에 맥주잔 2개.
- **대화할 때 입(부리) 모양을 대사에 맞춤**(사용자 필수 조건).
- 마지막 대사: **"이모! 맥주 한잔 더요!"**(사용자 지정. 원본의 "분유 한 병 더요? / 두 병이요?"를 대체).
