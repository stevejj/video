# 04. 샷리스트 템플릿과 컷 설명 규격

> 방침: 카메라 기법은 적지 않는다. 대신 **캐릭터의 표현력, 움직임, 장면**을 구체적으로 적는다.
> 이 규격대로 쓴 한 줄이 곧 Gemini 시작·끝 프레임 프롬프트와 Kling 동작 프롬프트의 원재료가 된다.

## 1. 컷 한 개의 필수 항목

| 항목 | 내용 | 예시 |
|---|---|---|
| 컷 번호 | 시퀀스-순번 | 2-03 |
| 컷 크기 | 전체 / 중간 / 확대 / 둘 | 중간 |
| 보여주는 것 | 이 컷이 시청자에게 전달할 한 가지 | 팽창수가 봉투 두 개를 들고 현관 앞에 서서 문을 어떻게 열지 난감해함 |
| 공간·구도 번호 | 공간 바이블의 기준 구도 | 현관 C1 |
| 시간대·조명 | 공간 바이블 시간표 기준 | 아침, 창광 좌측, 실내등 꺼짐 |
| 등장 | 캐릭터 | 팽창수 |
| **표정·시선** | 표정 시트 ID + 시선 방향 | 03 놀람에서 04 째려봄으로 / 문손잡이를 내려다봄 |
| **동작: 시작 자세** | 시작 프레임에 보일 자세 | 문 앞 정면, 양 날개에 봉투 하나씩, 발 모아 섬 |
| **동작: 끝 자세** | 끝 프레임에 보일 자세 | 왼쪽 봉투를 바닥에 내려놓고 허리 편 상태, 오른 날개엔 봉투 유지 |
| **인식 신호** | 시청자가 이 컷에서 무엇으로 상태를 알아채는가: 결과 상태 + 소리 + 자막. 과정은 기본 생략, 필요 시 축약 동작 하나 | 봉투 하나가 바닥에 놓여 있음 + 봉투 내려놓는 소리. (과정 없음) |
| 좌날개 / 우날개 | 시작→끝 점유 | 봉투A→없음 / 봉투B→봉투B |
| 문·소품 상태 | 시작→끝 | 현관문 닫힘→닫힘, 봉투A 손→바닥 |
| 대사·자막 | 화자 + 자막 원문(한 줄) / 텍스트 카드 | 창수: "이거 어떻게 열지..." |
| 시간대 | 아침/낮/저녁/밤 + 경과 여부 | 아침 (경과 없음) |
| 길이 | 초 | 5 |
| 다음 컷 연결 | 체이닝(끝=다음 시작) / 컷 | 체이닝 → 2-04 |
| 규칙 체크 | 03 규칙집 R1~R4 통과 여부 | R2 통과(내려놓기 선택) |

## 2. 표현력 서술 규칙
- 표정은 반드시 **표정 시트 ID**로 지정한다(01 기본, 02 활짝, 03 놀람, 04 째려봄, 05 졸림, 06 슬픔, 눈감음). 시트에 없는 표정은 쓰지 않는다. 필요하면 시트를 먼저 늘린다.
- 표정 전환이 있는 컷은 "A → B"로 적고, 시작 프레임은 A, 끝 프레임은 B로 생성한다. 한 컷에 전환은 1회. **단, 순간적 감정(놀람·웃음 터짐·화남 등)은 클립 안에서 전환하지 않는다.** 반응 컷으로 따로 빼고 시작 프레임부터 반응 표정으로 만든다(03 규칙집 R11, 리액션 문법). 샷리스트의 표정 열에 `[순간]` 또는 `[점진]`을 표기한다.
- 시선은 항상 대상이 있어야 한다(문손잡이, 상대, 창밖, 카메라). "허공"은 금지.
- 감정은 표정+자세로 표현한다. 예: 난감함 = 03 놀람 + 어깨(날개) 살짝 올림 + 시선을 양 날개에 번갈아. 형용사("난감하게")만 적지 않는다.

## 3. 움직임 서술 규칙
- 동사는 03 규칙집 3장의 펭귄 신체 규칙 안에서만: 걷기(뒤뚱), 돌아서기, 앉기, 일어서기, 눕기, 집기(끼우기), 내려놓기, 밀기, 고개 돌리기, 끄덕이기.
- 시작 자세와 끝 자세가 **같으면 그 컷은 정지 컷**이다. 정지 컷은 3초, 미세 움직임(숨, 눈 깜빡임)만 허용.
- 이동 거리는 키의 2.5배 이내(5초 기준). 넘으면 컷을 나눈다.
- 물건이 손(날개)에 들어오거나 나가는 순간은 가능하면 **확대 컷(인서트)**으로 따로 뺀다.

## 4. 장면 서술 규칙
- 프레임 안에 보이는 소품을 전부 나열한다(공간 바이블 고정 소품표에 있는 것만).
- 문·서랍·조명·창의 상태를 시작→끝으로 적는다.
- 배경에 사람이나 다른 펭귄은 없다(Q35·Q36).

## 5. 한 줄 예시 (재활용 쓰레기 편 가정, 규칙집 R1~R3 적용)

| 컷 | 크기 | 보여주는 것 | 표정·시선 | 시작 자세 | 끝 자세 | 과정·속도 | 좌/우 날개 | 문 | 길이 | 연결 |
|---|---|---|---|---|---|---|---|---|---|---|
| 2-01 | 중간 | 봉투 둘 들고 현관 앞에 섬 | 01 기본 → 03 놀람 / 문손잡이 | 문 앞 정면, 양 날개 봉투 | 같은 위치, 문손잡이 응시 | 거의 정지, 고개만 살짝 숙임 | A→A / B→B | 닫힘→닫힘 | 3 | 체이닝 |
| 2-02 | 확대 | 왼 봉투를 바닥에 내려놓음 | 01 기본 / 봉투 | 숙이기 시작 | 봉투 바닥, 날개 비움 | 천천히 숙였다 폄 | A→없음 / B→B | 닫힘 | 4 | 체이닝 |
| 2-03 | 중간 | 손잡이 돌려 문을 밖으로 밈 | 01 기본 / 손잡이→복도 | 왼 날개 손잡이에 | 문 활짝, 문틀 안에 섬 | 손잡이 돌리고 천천히 밀기 | 없음→없음 / B→B | 닫힘→열림 | 5 | 체이닝 |
| 2-04 | 전체(문틀+복도 보임) | 문턱을 넘어 복도로 나감 | 01 기본 / 복도 앞 | 문틀 안 | 복도에 전신, 문 열린 채 | 두 걸음 뒤뚱, 끝에 정지 | 없음 / B | 열림→열림 | 5 | 컷 |
| 2-05 | 확대 | 바닥 봉투를 다시 집음 | 01 기본 / 봉투 | 복도에서 몸 숙임 | 양 날개 봉투 | 천천히 집고 폄 | 없음→A / B→B | 열림 | 4 | 컷 |

이 표의 각 줄이 Gemini 프롬프트 2개(시작·끝)와 Kling 프롬프트 1개로 변환된다.

## 6. 한 줄 지시를 검증하는 절차 (예: "버스를 기다리고 있는 팽창수")

한 줄 지시는 그대로 생성에 넘기지 않는다. 아래 3단계를 거친다.

### 6.1 생성 전: 규칙집 질문표로 컷 명세를 펼친다

| 규칙 | 질문 | 이 컷의 답 |
|---|---|---|
| 세계관(02) | 공간이 정의돼 있나? | 없음 → 한국식 정류장을 펭귄 스케일로 신규 정의(표지판, 벤치, 쉘터, 안내판) |
| 사람·펭귄(Q35·36) | 다른 승객? 버스? | 없음. 버스가 보이면 운전자 문제 → 이 컷엔 버스 없음. 버스 도착 컷은 운전석 안 보이는 구도로 별도 |
| R5 개수 | 물건 개수 | 표지판 1, 벤치 1, 쉘터 1, 안내판 1 + 닫는 문장 |
| R2 날개 | 든 것 | 미지정 → 비움 |
| 표정·시선 | 표정, 시선 대상 | 미지정 → 01 기본, 시선은 버스 오는 방향(우측 프레임 밖) |
| 자세 | 서기/앉기 | 서 있음, 3/4 우향 |
| 시간·조명 | 시간대 | 미지정 → 아침, 자연광, 그림자 좌측 |
| 스케일 | 기준 | 표지판 1.6, 벤치 좌면 0.3 |
| 구도(02a) | 컷 크기, 세이프존 | 중간, 얼굴·표지판 12~72%, 하단 보도, 우측 비움 |
| 재질(Q8) | 그림체 | 배경 실제 재질, 캐릭터만 플러시 |
| 동작 | "기다린다"의 표현 | 정지 컷: 표정+시선 / 영상: 고개를 우측으로 돌려 도로를 봄 |

사용자에게 되묻는 것: 미지정 항목 중 기본값으로 가면 안 되는 것만(시간대, 든 것, 표정).

### 6.2 프롬프트 조립
[COMMON] + [CHARACTER] + 위 표를 문장으로 옮긴 장면 설명 + 개수 닫는 문장 + 스케일 문장 + 재질 문장 + 세이프존 문장.

### 6.3 생성 후: 06 체크리스트 + 이 컷의 인벤토리 대조
- 캐릭터 A1 전 항목
- 인벤토리: 표지판 1, 벤치 1, 쉘터 1, 안내판 1. 버스·사람·펭귄·가방·차량 0
- 스케일: 표지판 높이, 벤치 높이
- 시선: 우측 도로. 카메라 응시·허공이면 불합격
- 구도: 세이프존
- 상식: 한국 정류장으로 보이는가(외국식 표지·차량이면 불합격)
