# 01a. 추가 참조 이미지 생성 프롬프트 (Gemini / Nano Banana용)

> 사용법은 아래 "공통 규칙"을 먼저 읽고, 프롬프트는 영문 그대로 복사해서 쓴다.
> 결과물 파일명은 각 항목의 `저장 파일명`대로 저장해서 `assets/characters/<캐릭터>/`에 올린다.

## 공통 규칙

1. **요청마다 참조 이미지를 반드시 첨부한다.** 팽창수는 `pang-changsu_sheet_clean.png`, 팽미순은 `pang-misun_sheet_clean.png`. 투샷은 두 장 다 첨부.
2. **한 요청에 한 캐릭터, 한 이미지.** 여러 장을 한 번에 요청하면 캐릭터가 섞인다.
3. 프롬프트의 `[COMMON]` 블록과 `[CHARACTER]` 블록은 매번 그대로 붙인다. 바꾸는 건 `[SHOT]` 블록뿐.
4. 배경은 시트와 같은 **무지 베이지 스튜디오 배경**으로 통일한다. 배경이 있으면 참조 이미지로 쓸 때 배경까지 따라온다.
5. Gemini는 우하단에 별 워터마크를 넣는다. 캐릭터를 프레임 중앙에 두고 **우하단에 여백을 남기게** 해서 제거하기 쉽게 한다. 워터마크 제거는 제가 한다.
6. 생성 직후 아래 체크리스트로 확인하고, 하나라도 틀리면 저장하지 말고 재생성한다.
   - 팽창수: 털뭉치 있음, 볼터치 없음, 머리 진한 슬레이트 그레이
   - 팽미순: 털뭉치 없음, 분홍 볼터치 있음, 머리 밝은 은회색
   - 공통: 눈 흰자 없음, 부리 닫힘·주황, 손가락·팔·목·눈썹 없음, 2등신, 플러시 털 질감
7. 해상도는 가능한 최대로. 비율은 각 항목에 표기 (전신 3:4, 투샷 4:3, 표정 1:1).

## 블록 정의

### [COMMON] (모든 요청에 붙임)
```
Use the attached character sheet as the EXACT reference. Reproduce this character with zero design changes: same plush 3D rendered look with short velvet fur, same chibi proportions (head as large as the body, no neck), same huge round dark-brown eyes with a large white highlight and no sclera, same small glossy coral-orange beak closed in a gentle smile, same cream face panel that runs from around the eyes down to the chest, same light silver-grey belly, same short rounded flipper wings with no fingers, same small grey feet. Do NOT add eyebrows, eyelashes, teeth, tongue, fingers, hands, arms, a neck, clothing, accessories, text, or logos. Keep the same plain warm beige studio background and soft diffused lighting as the sheet. Leave empty space in the bottom-right corner of the frame.
```

### [CHARACTER] 팽창수
```
This character is Pang Chang-su: dark slate-grey head, back and wings; a single upright tuft of fur on the very top of the head that curls slightly to one side; NO blush on the cheeks. The tuft must be visible from every angle.
```

### [CHARACTER] 팽미순
```
This character is Pang Mi-sun: light silver-grey head, back and wings; a smooth rounded head with NO tuft on top; soft pink circular blush on both cheeks that is clearly visible.
```

## 생성 순서 권장
1 → 4 → 2 → 3 → 5 → 6~10. 1번(고해상도 정면)이 잘 나오면 그 이미지를 시트와 함께 추가 첨부해서 이후 요청의 참조로 쓴다. 4번(투샷)이 잘 나오면 이후 모든 투샷 장면의 기준이 된다.

## 실패 시 대응
- 털뭉치가 사라짐 / 볼터치가 사라짐: [CHARACTER] 문장을 [SHOT] 뒤에 한 번 더 반복해서 재요청.
- 손가락·팔 생김: "The wings are short rounded flippers with no fingers, pressed close to the body" 를 [SHOT] 끝에 추가.
- 눈에 흰자 생김: "The eyes are entirely dark brown with no white sclera, only the small white highlights" 추가.
- 배경이 바뀜: "plain flat warm beige background identical to the sheet, nothing else in the scene" 추가.
- 3번 이상 실패하면 그 항목은 건너뛰고 저에게 알려주세요. 프롬프트를 손보겠습니다.
