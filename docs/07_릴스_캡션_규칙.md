# 07. 릴스 캡션 규칙 — 모든 에피소드 공통 (2026-10-08 사용자 확정)

## 형식 (이 세 덩어리가 전부, 덩어리 사이 빈 줄)
```
우리집 <캐릭터>이는 <상황 한 문장>🐧

여러분들도 <시청자 집으로 끌고 가는 질문>?👇

#지독한미순 #팽창수 <편별 태그 최대 3개>
```

## 기준 예시
ep02 (사용자 작성, 2026-10-09):
```
우리집 미순이는 움직이지 않아요🐧

여러분들도 집에 미순이가 있나요?👇

#지독한미순 #팽창수 #팽미순 #커플일상 #좀줘
```
ep01 (추천안, 사용자 "이런 느낌으로 써야 읽기 좋네"):
```
출근하면 3시가 제일 안 가요🐧

여러분은 몇 시가 제일 길어요?👇

#지독한미순 #팽창수 #직장인일상 #퇴근 #펭귄
```

## 규칙
1. **첫 줄 = 상황 한 문장.** 가능하면 "우리집 미순이는/창수는 ~" 꼴로 캐릭터 이름을 넣는다. 구어체, 15자 안팎, 끝에 🐧(띄어쓰기 없이).
2. **둘째 줄 = 댓글 질문 하나.** "여러분들도 집에 ○○이가 있나요?"처럼 시청자 집으로 끌고 가는 질문, 끝에 👇. 첫 줄과 사이에 빈 줄 하나.
3. **영상 속 대사·자막을 나열하지 않는다.** 화살표 요약도 쓰지 않는다.
4. **해시태그 최대 5개.** 채널 고정 2개(#지독한미순 #팽창수) + 미순 출연 편은 #팽미순 + 편별 1~2개.
5. 제목·대사가 바뀌면 캡션도 다시 쓴다. 편별 캡션은 `docs/<ep>/..._릴스_캡션.md`에 복사용 블록으로 둔다.
6. 커버 프레임은 제목 밴드가 보이는 세로 프레임 그대로, 가장 웃긴 컷에서 고른다.
