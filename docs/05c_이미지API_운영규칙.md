# 05c. 이미지 API(Nano Banana) 운영 규칙 (v1.0)

> 2026-09-16 사용자 결정: 이미지는 Gemini 앱 수작업 대신 **Google Nano Banana API**로 내가 생성한다. 충전 10,000원.
> 원칙: **한 장씩 생성 → 보여주기 → 사용자 판단**. 배치는 사용자가 범위를 지정한 경우에만, 리스크·예상 비용을 적고 "진행할까요?"를 물어 "알겠다"를 받은 뒤 실행.

## 1. 모델 비교 (ai.google.dev 가격·문서, 2026-09-16 확인, 환율 1,400원/$)

9:16 실제 픽셀: 0.5K ≈ 384x688, **1K ≈ 768x1376**(사용자가 Gemini 앱에서 만든 시트와 동일), 2K ≈ 1536x2752, 4K ≈ 3072x5464(Kling 입력 한도 초과).
Kling 출력은 720p(720x1280)이므로 **1K 입력이면 충분**하다.

| Nano Banana 2 (Flash) | gemini-3.1-flash-image | **94원** | 141원 | 물체 10, 캐릭터 4, 스타일 3 | 속도·가격·참조 수 균형. 캐릭터 참조 4장 = 우리 필요(시트, 정면, 자세, 부위)에 맞음 | **기본** |

입력 비용(참조 이미지·프롬프트)은 장당 1~3원. API 출력에는 보이는 워터마크 없음(SynthID 비가시만).

## 2. 해상도 정책 (수정)
- **전부 1K**. 시트·공간·프레임 모두 768x1376이면 Kling 720p에 충분. 2K는 쓰지 않는다.

## 4. 절차
1. 사용자가 "다음 이미지 진행"이라고 하면 → 프롬프트·참조·해상도·예상 비용을 한 줄로 보이고 실행(한 장).
2. 결과 이미지를 보여주고 06 체크리스트로 검수 결과 첨부 → 사용자 판단(채택 / 수정 재생성 / 폐기).
3. 배치 요청("P-1~P-4 한 번에")이 오면 → **범위, 각 장 프롬프트 요약, 리스크(앞 장 결과를 못 보고 만드는 데서 오는 것), 예상 비용, 진행 여부 질문** → "알겠다" 후 실행.
4. 매 호출 `outputs/nb_log.jsonl`에 기록, 누적 비용 표시.
5. 재시도: 사용자 지시 없이는 재생성하지 않는다. (자동 재시도 없음)

## 5. 키 관리
- API 키는 환경변수 `GEMINI_API_KEY` 또는 저장소 루트 `.env`(gitignore 됨)에만 둔다. 채팅·문서·커밋에 넣지 않는다.
- 권장 전달 경로: Claude Code 환경 설정의 환경변수. 채팅으로 주면 .env에 옮기고 채팅 기록에 남으므로 작업 후 키 교체를 권장.
