3. 스토리보드 미결 2개는 그대로 열려 있음: 요청 횟수 7회 vs 5회(5회면 14·16컷 중 하나와 UI 17 삭제, 이미지 4장 감소), Kling 충전 시점(잔액 163 → 목표 480~550).
