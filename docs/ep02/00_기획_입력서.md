# ep02 기획 입력서 (사용자가 채우는 칸만 모음, 2026-10-01)

ep01에서 확정된 규칙(02a 레이아웃, 02c 움직임, 04 §1b 대사, 05e 음성, 효과음·BGM)은 전부 자동 적용된다. 아래만 정해주면 스토리보드·실행표·예산을 내가 만든다.

## 1. 한 줄 전제
- 제목(두 줄, 2줄째가 노란 강조): `오늘도 / ______`
- 상황 한 문장: (예: "미순이 라면 끓이는 동안 창수가 설거지를 미룬다")
- 장르: 코미디 / 감성 (소리 규칙이 갈림: 코미디=만화 효과음·환경음 최소, 감성=사실 폴리·3단 BGM)

## 2. 3막 (각 1~2문장)
| 막 | 내용 | 끝나는 감정 |
|---|---|---|
| 시작(0~15s) | | |
| 중간(15~45s) | | |
| 펀치라인(45~60s) | | |
- 반전/펀치라인이 터지는 **정확한 순간** 하나: ______ (여기에 쿵+정적 또는 BGM 교체가 붙는다)

## 3. 대사·리액션 (02c·05e 규칙)
- 대화(주고받기) 2~3회: 누가 → 누가, 각 8~12음절
- 혼잣말(속마음, 동굴 울림) 3~5줄
- **목소리 리액션** 5개 이상(웃음·한숨·비명·숨흡입·코골이). 10초당 1개
- 외침(늘려 쓰는 대사) 1~2줄: 예 "퇴그으은!!"

## 4. 움직임 (02c M2) — 반드시 "동작"으로 보여줄 장면 3개 이상
- (예: 라면 젓가락질, 설거지 미루고 소파에 눕기, 미순이 창수를 노려보며 다가오기)

## 5. 화면 속 UI 인서트 (02c M3, 0크레딧) 있으면
- (예: 휴대폰 메신저 "설거지 했어?", 배달앱 화면, 시계)

## 6. BGM 구간 (05e §11)
- 기본 BGM 결: (귀엽고 잔잔 / 경쾌 / 없음)
- 음악이 바뀌거나 멈추는 지점: 펀치라인에서 (정적 / 어두운 곡 교체)

## 7. 예산
- Kling 잔액: ____ (제작 시작 전 확인. 목표 300~350)
- 컷 수 목표: 24~30, 캐릭터 클립 16~20개

---
채우면 내가 하는 일: 스토리보드(27컷 규격+움직임 4칸) → 이미지 프롬프트 → 실행표(5단계 승인) → 음성·효과음·BGM → 조립 → 정지 초 검증 → 릴스 레이아웃 검증.
