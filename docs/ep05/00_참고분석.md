## 2. 왜 이해되나 (F3)
1. **누구나 아는 행동**: 헬스장에서 운동은 안 하고 인증샷만 찍는 사람. 설명이 필요 없는 공감 상황.
2. **폰이 화면에 보임**: 남자가 폰을 들고 있어 "사진 찍는 중"이 바로 읽힘.
3. **반전이 즉시**: 찍자마자 덤벨을 내려놓음 → "운동은 사진용"이 1초 만에 전달.
4. **확인 → 재촬영**: 사진 확인 후 다시 포즈 = 마음에 안 듦(설명 없이 행동으로).
5. **루프**: 끝 = 처음. "또 찍네"가 반복 시청을 부름.
6. **배경·소품이 장소를 말함**: 덤벨 랙, 고무 바닥, 운동복.
