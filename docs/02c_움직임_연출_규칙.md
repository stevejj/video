# 02c. 움직임 연출 규칙 (2026-10-01, 참조 채널 3편 화면 분석 + ep01 반성)

## 0. 왜 필요한가 — ep01 실측
| | ep01 (우리) | 참조 3편 (일희일BEE·A.S.A.P·총량의법칙) |
|---|---|---|
| 완전 정지 컷 | **18/27개, 40초 = 64%** (2% 줌만) | **0개** (3편 모두 "1초 단위로 아무것도 안 변하는 구간 0초") |
| 움직이는 컷 | 9개, 22초 = 35% | 전부 |
| 평균 컷 길이 | 2.3초 | 1.4 / 1.8 / 2.8초 |
| 일상 동작(타자·밥·걷기) | 정지 사진 + 효과음 | 실제 동작 애니메이션(앞발 타자, 피자 베어물기, 빨대) + 화면 속 UI 인서트 |
| 리액션 | 표정 사진 컷 | 컷 전환 + **줌 펀치**·미세 흔들림·반짝 그래픽 + 상태 자막 팝업 |
| 카메라 | 고정 | 고정 70~80% + 감정 컷에 느린 푸시인/줌 펀치 |
| 컷 전환 | 하드컷 + 암전 1회 | 하드컷 100% |
| 자막 | 한 번에 표시 | 팝업 등장, 키워드 거대화, 괄호 상태 자막 "(끄덕끄덕)" |

**근본 원인**: 03 규칙집의 "과정은 보여주지 않는다, 결과 상태 + 인식 신호(효과음·자막)로 전달"이 **정지 사진을 정답으로 만든 규칙**이었다. 크레딧 절약(전략 B)과 이미지 우선 제작이 겹쳐 "사진 슬라이드쇼 + 효과음"이 됐다. 참조는 정반대다: **동작 자체가 컷의 내용**이고, 효과음은 동작에 붙는다.

## 1. 규칙 M1~M10
### M1. 정지 컷 금지 — 모든 컷에 "눈에 보이는 변화"가 있어야 한다
- 1초 안에 캐릭터·소품·카메라·그래픽 중 **하나는 반드시 움직인다**. 2% 줌은 움직임으로 치지 않는다.
- 검수: 조립 후 1초 단위 프레임 차이를 재서 변화 없는 초가 있으면 불합격(06 체크리스트 B-M1).

### M2. 일상 동작은 동작으로 보여준다 (03 규칙집 "과정 생략" 범위 축소)
- 타자·먹기·마시기·걷기·전화 보기·고개 돌리기·기지개·조는 것 같은 **반복·일상 동작은 Kling 클립으로 만든다.** 효과음만으로 대신하지 않는다.
- "과정 생략"은 펭귄 신체로 불가능하거나 길이가 긴 것(의자 오르내리기, 문 열기, 옷 입기)에만 적용한다(R9-6 유지).
- 프롬프트 예: `his wing tips tap the keyboard keys rapidly and continuously from the very first frame` / `he lifts the spoon to his beak, takes a bite and chews with small cheek movements`.

### M3. 화면 속 UI 인서트는 그래픽으로 움직인다 (크레딧 0)
- 휴대폰·메신저·캘린더·모니터 화면은 **인서트 컷**으로 따로 빼고, 글자가 타이핑되는 애니메이션·알림 팝업을 조립 단계에서 ffmpeg로 그린다. 참조 A.S.A.P는 33컷 중 9컷이 UI 인서트.
- 캐릭터 컷 → UI 인서트 → 리액션 컷의 3박자 교차가 "영상답다"의 핵심 리듬.

### M4. 리액션에는 편집 효과를 붙인다 (크레딧 0)
- 표정이 바뀌는 컷에 **줌 펀치**(0.15초 안에 6~12% 확대), 충격엔 미세 흔들림, 기쁨엔 반짝 그래픽, 멘붕엔 땀·물음표. edit_list의 `fx` 칸으로 지정.
- 리액션 컷은 짧게(1.0~1.5초), 얼굴 클로즈업.

### M5. 컷 길이와 수
- 평균 1.5~2.5초. 60초 편은 **24~35컷**. 한 컷 3초 이상은 걷기·먹기 같은 동작 컷에만.
- 대화는 숏-리버스-숏: 말하는 쪽 컷 ↔ 듣는 쪽 리액션 컷을 1초 간격으로 교차.

### M6. 표정 변화 (R11 유지)
- 점진 변화(졸림→감김)는 클립 안에서, 순간 변화(놀람·분노)는 컷 전환으로. 순간 변화 컷엔 M4 효과 필수.

### M7. 카메라
- 기본 고정. 감정이 오르는 컷에만 느린 푸시인(3초에 4~6%, 조립에서). 참조는 고정 70~80%.
- 전환은 하드컷만. 디졸브·와이프 금지. 암전은 "하루 끝" 같은 구조적 전환 1회만.

### M8. 자막 연출
- 자막은 **팝업**(0.1초 확대 등장). 강조 키워드는 화면 폭 절반까지 거대화 1회/편.
- 괄호 상태 자막 "(끄덕끄덕)", "(타다다닥)", "(몸이 굳는 단어)"를 캐릭터 옆에 띄운다. 효과음 자막은 ep01 4-02에서 시작한 방식 유지.

### M9. 1초 규칙 검증 도구
- `tools/verify_motion.py`(만들 것): 조립본을 1초 창으로 훑어 프레임 차이 < 임계값인 구간을 나열. 보고서에 "정지 초 수"를 적는다. 목표 0초.

### M10. 기획 템플릿 칸 추가 (04 §1)
- 컷마다 **움직임 4칸**: (a) 캐릭터 동작 (b) 소품·UI 변화 (c) 카메라 (d) 편집 효과. 넷 다 "없음"이면 기획 통과 불가.

## 2. 크레딧 현실과 전략 C′
- ep01은 Kling 163 남음. M1·M2를 지키면 **거의 모든 컷이 클립**이다. 3초 = 18크레딧 기준:
  - 60초 편 28컷 전부 클립 ≈ 500 크레딧 (충전 필요)
  - **권장**: 캐릭터 컷 18개만 Kling(≈ 330), UI 인서트 6개(M3, 0크레딧), 리액션 클로즈업 4개는 짧은 2초 클립 또는 **표정 시트 2장 교차+줌 펀치**(0크레딧)
- 정지 이미지를 쓸 수밖에 없는 컷은 **M3·M4·M7 효과를 최소 2개** 얹어 "정지"를 숨긴다(줌 펀치 + 상태 자막 팝업 등).
- 결론: 다음 편 제작 전 Kling 크레딧 **300~350 확보**가 전제. 못 하면 컷 수를 16~18개로 줄이고 전부 클립으로 간다(정지 컷 섞는 것보다 낫다).

## 3. ep01에 크레딧 0으로 적용 가능한 것 (원하면 v11)
- 리액션 컷(4-03·9-03·10-03) 줌 펀치, 7-01 반짝 그래픽, 10-03 흔들림
- 정지 컷 줌 2% → 5~6% 푸시인(감정 컷만)
- 자막 팝업 등장, 상태 자막 "(끄덕끄덕)" 추가
- 4-02 키보드 컷: 모니터 화면에 타이핑되는 글자 인서트(UI 그래픽)

## 4. HyperFrames 역할 분담과 퍼펫 한계 (2026-10-07, ep01 v11 실측 → ep02부터 적용)

ep01 v11(`docs/05f`)에서 확인한 것: HyperFrames는 **카메라·자막·UI·효과에는 완벽**하고, 캐릭터 부위를 오려 움직이는 **컷아웃 퍼펫은 잔상(배경 메움 자국·가장자리 번짐)이 남는다**(사용자 확인: 키보드 날개·눈 깜빡임). 그래서 기획 단계에서 아래처럼 나눈다.

| 움직임 종류 | 담당 | 비고 |
|---|---|---|
| 캐릭터 부위 동작(걷기·건네기·고개 돌림·부리·깜빡임·앉기) | **Kling 클립** | 퍼펫으로 대체하지 않는다. 깜빡임·끄덕임도 얼굴 확대 컷에서는 잔상이 보이므로 Kling |
| 카메라(푸시인·풀아웃·팬·드리프트), 줌 펀치·흔들림 | **HyperFrames** (0크레딧) | `hf_fx.json`. 정지 컷을 쓸 때의 유일한 생명줄 |
| 자막 팝·외침 오버슈트·크기 점증, 시간 카드, 반짝 그래픽 | HyperFrames | 전부 CSS/GSAP |
| UI 인서트(카운터·화살표·점선 동그라미·시계) | HyperFrames | 그래픽이라 잔상 없음, 0크레딧 |
| 컷아웃 퍼펫 | **원칙적으로 안 씀** | 예외: 전체 샷에서 부위가 작고(머리 폭 < 프레임 10%) 진폭이 5px 이하이며 뒤 배경이 단색일 때만, 그것도 사용자 승인 후 |

- **M11. 정지 컷은 "카메라+효과만"으로 살린다.** 캐릭터가 움직여야 하는 장면을 정지 컷으로 잡고 퍼펫으로 때우지 않는다. 움직임이 필요하면 스토리보드에서 Kling 클립으로 잡고 예산에 넣는다.
- **M12. 잔상 체크.** 퍼펫을 예외로 썼다면 06 검수에 "B-M5 퍼펫 잔상: 움직인 부위 주변 1초 프레임 3장 비교, 자국이 보이면 퍼펫 제거"를 추가한다.
- **M13. UI 삽입물(카운터·시계·팝업 등)은 기본 넣지 않는다.** 스토리보드에 UI 컷이 있어도 가편집 전에 사용자에게 "이 컷 넣을까요?"를 먼저 묻는다. 캐릭터 없는 그래픽 컷은 템포를 끊고 "왜 넣었지?"가 되기 쉽다(ep02 8컷 카운터 삭제, 2026-10-08). 실물 인서트(리모컨 클로즈업처럼 장면 안 사물을 크롭한 것)는 예외.
- 조립은 ep02부터 HyperFrames가 기본(`tools/ep_to_hyperframes.py`), 오디오 믹스는 당분간 ffmpeg(`assemble_ep01.py`의 믹스 단계) → mux.
