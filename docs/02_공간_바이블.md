## 0. 세계관·스케일 (확정)

### 0.1 세계 규칙
- 이 세계의 "사람"은 펭귄이다. 팽창수와 팽미순 두 캐릭터만 등장한다. 다른 펭귄은 없다.
- 모든 공간은 **평범한 한국식 공간**(아파트, 회사, 편의점 등)이다. 외관, 자재, 가구, 가전, 소품은 현실의 한국 것과 같다. 장난감·미니어처·동화풍으로 만들지 않는다.
- 단, **모든 크기는 펭귄 몸 기준**이다. 문은 펭귄이 지나갈 만큼, 의자는 펭귄이 앉을 만큼, 컵은 펭귄이 두 날개로 들 만큼. 사람 크기 가구에 작은 펭귄이 사는 세계가 아니다.
- 사람은 필요하면 등장시키되 **얼굴이 나오지 않는 선**에서, "사람이구나" 인식되는 정도로만(뒷모습, 어깨 아래, 멀리 흐리게, 실루엣, 손만). 펭귄과 같은 키. 대사·표정·이름 없음. 한 컷 2명·3초 이내. 물건 주고받기는 손 인서트로. 상세는 `02b_세계관_사례집.md`.
- 펭귄은 외형일 뿐이다. 사람처럼 더위·추위를 느끼고 사람 음식을 먹는다. 펭귄 생물 개그는 쓰지 않는다.
- 둘 다 회사원. 회사 배경은 그 주제에서만 짓는다.
- 집은 아파트. 공간은 거실, 서재, 침실, 화장실 4개로 일단 고정. 층수·엘리베이터는 표현하지 않는다. **한 번 지은 집은 모든 영상에서 동일**하게 쓴다. 새 주제가 새 공간을 요구하면 내가 분석해 보고하고 승인 후 추가한다.
- 차 있음, 대중교통도 이용. 결혼 3년차(주제상 필요할 때만 드러냄). 외출 준비 신호는 현관문 앞 + 열쇠·휴대폰 인서트(주제별 다른 표현은 반드시 확인).

### 0.2 스케일 기준값
캐릭터 키(정수리~발바닥, 털뭉치 제외) = **1.0 단위**. 모든 공간·소품 크기는 이 단위로 적는다.

| 대상 | 크기(단위) | 근거 |
|---|---|---|
| 현관문·방문 높이 | 1.6 | 사람 문 2.1m / 사람 키 1.7m 비율에 여유 |
| 문손잡이 높이 | 0.55 | 날개 끝이 닿는 높이(날개는 몸 옆 중간에서 나옴) |
| 식탁·책상 높이 | 0.55 | 서서 배 아래, 앉아서 가슴 높이 |
| 의자 좌면 높이 | 0.3 | 앉았을 때 발이 바닥에 닿는 높이 |
| 소파 좌면 높이 | 0.3 | 동일 |
| 침대 높이 | 0.3 | 올라가기 쉬운 높이 |
| 싱크대·조리대 높이 | 0.55 | 식탁과 동일 |
| 냉장고 높이 | 1.4 | 위 칸은 까치발 |
| 머그컵 | 0.3 | `pang-*_pose_hold_cup.png` 기준(머리 높이의 약 1/3) |
| 휴대폰 | 0.25 x 0.12 | 한 날개로 쥐는 크기 |
| 창문 아래턱 높이 | 0.5 | 서서 밖이 보이는 높이 |
| 천장 높이 | 2.0 | 와이드샷 여유 |

이 표는 스케일 시트 이미지 생성 후 실제 결과에 맞춰 조정한다.

### 0.3 스케일 시트 (생성 예정)
- 팽창수가 현관문, 식탁+의자, 소파, 머그컵 옆에 나란히 선 이미지 1장(9:16).
- 이후 모든 공간 기준 컷 생성 시 참조로 첨부해 크기를 고정한다.
- 프롬프트는 `01a` 문서에 추가 예정(Q11 이후).
