화면 글자: 상단 고정 "한 입도 안 먹겠다던 내 여자친구:" + 영문. 끝까지 유지.

## 2. 왜 이해되나 (F3)
1. **전제를 화면 글자가 준다**: "한 입도 안 먹겠다던 내 여자친구:" — 영상이 시작하자마자 "이 여자는 결국 먹는다"를 예고. 시청자는 *언제·어떻게 먹나*만 기다린다.
2. **소품 대비가 설정을 보여 준다**: 샐러드(다이어트) vs 쿠키(유혹). 말 없이 "다이어트 중"이 읽힘.
3. **욕망 컷이 따로 있다**: 여자 클로즈업에서 눈이 쿠키로 감. 행동 전에 *원함*을 먼저 보여 줌.
4. **손이 닿는 거리**: 둘이 붙어 앉고 그릇이 남자 무릎 = 여자 손 바로 옆. 몸을 늘이거나 일어날 필요 없음.
5. **결과를 인서트로 보여 준다**: 빈 그릇 클로즈업 = 펀치라인. "다 먹었다"를 한 장으로.
6. **결말이 갈등이 아니라 애교**: 들켜도 기대며 웃음 → 커플 공감, 귀여움으로 끝.
7. **컷을 나눈다**: 와이드 → 클로즈업 → 인서트. 각 컷이 한 가지 정보만 줌(먹는다 / 원한다 / 훔친다 / 다 먹었다 / 애교).
