# ep01 이미지 작업 분담 계획 (제안, 승인 대기)

> 원칙: **판단·반복이 필요한 첫 장은 사용자가 Gemini 앱에서(무료, 즉시 확인)**, **검증된 패턴을 물려받는 나머지는 내가 API로(유료, 사용자 시간 절약)**.
> 앱 결과는 업로드 → 내가 검수·워터마크 제거·저장. API 결과는 생성 요청서 → 승인 → 생성 → 검수.

## 3. 순서와 흐름
1. 사용자: 스케일 시트 → 업로드 → 검수
2. 사용자: 공간 기준 컷 10장(한 번에 10개 프롬프트를 드림, 앉은 김에 몰아서) → 업로드 → 검수
3. 사용자: 그룹 첫 프레임 13장(공간별로 프롬프트를 드림) → 업로드 → 검수
4. 나: 통과된 첫 프레임마다 배치 후보를 제시 → 승인 → API 생성 → 검수 결과 보고
5. 실패 재시도: 앱(무료)이 기본. 사용자가 바쁘면 API로 전환(승인 후)

## 4. 시간 감각
- 앱 1장: 프롬프트 붙여넣기 + 참조 첨부 + 생성 + 업로드 ≈ 1~2분. 24장 + 재시도 ≈ 40~60분, 여러 번에 나눠서.
- API 1장: 생성 30~40초 + 내 검수. 20장 ≈ 20~30분, 사용자는 승인·판단만.

## 5. 비용
- 원안(전부 API): 약 6,100원 → **이 계획: 약 2,500원**. 잔여 예산은 재시도와 다음 에피소드로.

## 6. 사용자 확인 사항
- 분담 비율(앱 24 / API 20)이 괜찮은지. 앱 몫을 더 줄이고 싶으면 공간 기준 컷 10장을 API(Lite, 470원)로 넘길 수 있음.
- 공간 기준 컷 10장 프롬프트를 지금 한 번에 받을지.
