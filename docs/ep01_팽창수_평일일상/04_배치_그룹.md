# ep01 배치 그룹 (통과된 이미지 → 물려받는 컷)

> 05c 4.4의 "배치 후보" 목록을 ep01에 미리 적용한 표. 실제 제시는 각 이미지가 통과된 시점에 다시 한다.
> 규칙: 배치는 같은 공간·구도·시간대·캐릭터 구성. 체이닝 컷의 다음 시작 프레임, 새 공간 첫 컷, 둘 컷 첫 장은 배치 불가(한 장씩).

## 0단계. 시트·스케일 (모두 한 장씩. 서로 참조하지 않음 → 사용자가 원하면 5장 배치 가능, 리스크 낮음)
P-1 발, P-2 창수 날개, P-3 미순 날개, P-4 털뭉치, P-5 스케일 시트

## 1단계. 공간 기준 컷 (Lite). 스케일 시트 통과 후
| 통과 이미지 | 물려받는 후보 |
|---|---|
| 스케일 시트 | S-B1a 침실 아침, S-T1, S-S1, S-O1a, S-R1, S-P1, S-P2, S-L1 (서로 독립, 배치 가능) |
| S-B1a | S-B1b 침실 밤 |
| S-O1a | S-O1b 사무실 저녁 |

## 2단계. 프레임 (Flash). 공간 기준 컷 통과 후
| 통과 이미지 | 물려받는 후보(시작 프레임) | 배치 불가 |
|---|---|---|
| S-B1a + 캐릭터 참조 → 1-01 시작 | 1-03 시작 | 1-02(B2 구도 첫 장) |
| S-B1b → 10-01 시작 | — | 10-02(B2 밤 첫 장) |
| S-T1 → 2-01 시작 | — | 2-02(2-01 끝 프레임 체이닝) |
| S-S1 → 3-01 시작 | 3-02 시작, 8-01 시작(표정만 다름) | — |
| S-O1a → 4-01 시작 | 4-03 시작, 6-03 시작 | 4-02(인서트 첫 장) |
| S-O1b → 7-01 시작 | — | — |
| S-R1 → 5-01 시작 | 5-02 시작, 5-03 시작 | — |
| S-P1 → 6-01 시작 | 6-02 시작 | — |
| S-P2 → 9-01 시작(둘 컷 첫 장, 단독) | 9-02, 9-03 시작 | — |
| S-L1 → 9-04 시작(둘 컷, 단독) | — | — |

끝 프레임은 해당 시작 프레임이 통과된 뒤 한 장씩(같은 물건·개수·색 유지 검수가 필요). 시작 프레임이 여러 장 통과되면 그 끝 프레임들을 배치 후보로 제시한다.
