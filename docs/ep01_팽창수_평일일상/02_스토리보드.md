## 톤 설계 (E6)
- 반복·지루·피곤. 창수의 기본 표정은 05 졸림과 12 생각중. 풀리는 얼굴은 저녁 산책 마지막 한 컷뿐.
- 속마음 자막은 전부 1인칭, 짧게. 순서: "또 아침.." → "가기 싫다.." → "이거 또해.." → "모니터 뚫어!!!!" → "밥 마시따" → "졸려..." → "후..." → "아직도 3시.." → "아직도 4시.." → "아직도 5시.." → "퇴근!!" → "빨리집가!!!" → 미순 "라면머글래?" → 창수 "끄래!!!" → (거실 TV, 자막 없음) → "내일도 화이띵...!" → (다시 07:00) "아!!!!!!!!!!!!!!!!"
- "모니터 뚫어!!!!"에서 짜증이 터지고, 같은 사무실 컷이 3시·4시·5시로 세 번 반복되며 시간이 안 가는 오후를 시청자가 몸으로 느끼게 한다. "퇴근!!"과 "빨리집가!!!"로 두 번 튀고, 라면 한 마디에 눈이 동그래지며 풀리고, 소파에서 TV 보는 조용한 컷을 지나 "내일도 화이띵...!"으로 잠든다. 그리고 **첫 컷(07:00 알람)이 그대로 다시 나오며 "아!!!!!!!!!!!!!!!!"** — 하루가 또 시작된다는 루프로 끝난다.
- 자막 표기 규칙: 속마음은 마침표 대신 ".."(2개) 또는 "..."(3개). 느낌표는 짜증("모니터 뚫어!!!!"), 해방("퇴근!!"), 기쁨("끄래!!!"), 마지막 다짐에만.
> 표기: 표정은 캐릭터 바이블 ID. 날개는 좌/우. 시간 카드는 오버레이. 모든 컷 카메라 고정·눈높이, 배경 실제 재질·캐릭터만 플러시, 세이프존 적용.
