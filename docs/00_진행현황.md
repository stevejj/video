## 미결 질문 (번호 순서대로 하나씩 답해주세요)

답을 주시면 해당 줄에 `→ 답:` 으로 기록하고 체크합니다. 순서는 권장 순서일 뿐, 편한 것부터 답해도 됩니다.

### A. 캐릭터 (G1)

- [ ] **Q1. 옷을 입나요?** 현재 시트는 알몸 펭귄입니다. 부부 일상(외출, 잠자리, 요리)을 그리려면 "옷 없음"으로 갈지, 최소 소품(앞치마, 목도리, 안경, 잠옷)만 쓸지, 아예 의상을 입힐지 정해야 합니다. 옷을 입히면 일관성 관리 대상이 두 배가 됩니다. 권장: 옷 없음 + 장면별 소품 1개 이내.
- [ ] **Q2. 키·체구 차이가 있나요?** 두 시트는 같은 체형입니다. 팽창수를 조금 크게 할지, 동일하게 갈지. 권장: 동일 체형(왜곡 위험 최소).
- [ ] **Q3. 나이대와 성격.** 신혼인지 중년 부부인지, 각자 성격(예: 팽창수 느긋·덜렁, 팽미순 꼼꼼·잔소리). 행동 연출과 표정 설계의 기준입니다.
- [ ] **Q4. 팽창수의 볼터치.** 팽창수는 볼터치 없음으로 고정할까요? 시트에는 거의 없습니다. 권장: 없음(두 캐릭터 구분 요소로 사용).
- [ ] **Q5. 표정 범위.** 필요한 표정 목록을 정합니다. 제안: 기본 미소, 활짝 웃음, 놀람, 삐침/화남, 졸림, 슬픔(눈물). 이 중 쓸 것만 고르세요. 표정마다 참조 이미지를 만들어야 합니다.
- [ ] **Q6b. 극단 표정에서 흰자 허용?** 팽창수 표정 시트의 놀람·째려봄 칸에 흰자가 생겼는데 플러시 스타일에서는 자연스러워 보임. 허용하면 규칙을 "기본 표정은 흰자 없음, 놀람·째려봄에만 소량 허용"으로 완화. 권장: 허용하되 영상 생성 시 놀람 컷은 부리 닫힘 유지.
- [ ] **Q6. 입(부리) 열림.** 말하는 장면에서 부리를 벌릴 건지, 항상 닫힌 미소로 갈지. AI 영상에서 부리 개폐는 왜곡 주요 원인입니다. 권장: 부리 닫힘 고정, 대사는 자막/나레이션.
- [ ] **Q7. Google Flow에서 겪은 캐릭터 왜곡 사례.** 구체적으로 무엇이 바뀌었나요? (얼굴형, 눈 크기, 색, 털 질감, 손발, 비율 등) 금지 항목에 반영합니다.
- [ ] **Q8. 그림체 고정.** 현재 시트의 "봉제인형 플러시 3D 렌더" 질감을 그대로 유지할까요? 배경(집)도 같은 플러시/미니어처 디오라마 느낌으로 갈지, 배경은 일반 3D 애니메이션 느낌으로 갈지 정해야 합니다. 권장: 배경도 미니어처 디오라마 질감(캐릭터와 이질감 최소).
- [x] **Q9. 추가 참조 이미지 생성 승인.** → 답: 사용자가 Gemini에서 직접 생성. 프롬프트는 `docs/01a_추가참조이미지_프롬프트.md`. 모바일용 복사 도구: https://claude.ai/artifact/XYXEbtLVfEaLPaHofC12e6 (소스 `tools/prompter/index.html`). 결과물 업로드 대기 중.
  - 원문: 아래 "추가로 필요한 캐릭터 이미지" 목록을 Nano Banana로 만들 예정입니다. 이건 기획 자산이라 G6 이전에 생성해도 되는지 확인 바랍니다. (사용자가 직접 만들어 올려주셔도 됩니다.)

### B. 공간 (G2)

- [ ] **Q10. 집 형태.** 한국 아파트인지, 단독주택인지, 아니면 펭귄 세계관의 가상 집(이글루 등)인지.
- [ ] **Q11. 등장 공간 목록.** 현관, 거실, 주방, 침실, 욕실, 베란다, 집 밖(복도·엘리베이터·골목) 중 첫 에피소드에 필요한 것만.
- [ ] **Q12. 평면 관계.** 손그림 평면도가 있으면 올려주세요. 없으면 제가 초안을 그려 확정받겠습니다.
- [ ] **Q13. 인테리어 톤.** 색감(예: 우드+화이트, 파스텔), 시대감(현대), 정리 상태(깔끔/생활감).
- [ ] **Q14. 공간별 고정 소품.** 소파 색, 식탁, 냉장고, 침대, 현관 신발장 등. 없으면 제가 제안.
- [ ] **Q15. 시간대·계절.** 첫 에피소드의 계절과 시간 흐름(아침→밤인지, 저녁 한 장면인지).
- [ ] **Q16. 창밖 풍경.** 아파트 창밖에 뭐가 보이는지(도시, 나무, 바다). 반복 등장하므로 고정 필요.

### C. 현실감 규칙 (G3)

- [ ] **Q17. 생활 기준.** 한국 생활 상식 기준으로 규칙을 쓰면 되나요? (현관문 바깥 열림, 나갈 땐 도어락 안 누름, 신발 벗고 들어옴, 좌식/입식 등)
- [ ] **Q18. 부부의 하루 동선.** 누가 출근하는지, 재택인지, 기상 순서, 식사 담당.
- [ ] **Q19. Flow에서 겪은 현실감 오류 사례.** 문 방향, 비밀번호 외에 기억나는 것 전부.
- [ ] **Q20. 펭귄 신체 규칙.** 날개로 물건을 잡는 것을 허용할지(의인화 정도). 컵을 들거나 문을 여는 동작을 어떻게 표현할지. 권장: 날개 끝으로 잡되 손가락은 절대 생기지 않음.

### D. 에피소드 (G4)

- [ ] **Q21. 첫 에피소드 줄거리.** 한 문단이면 됩니다.
- [ ] **Q22. 형식.** 쇼츠 세로 9:16 / 유튜브 가로 16:9, 총 길이(초).
- [ ] **Q23. 대사·음성.** 자막만 / 나레이션 / 캐릭터 목소리(TTS). 립싱크 여부(Q6과 연결).
- [ ] **Q24. 톤.** 잔잔한 힐링 / 코믹 / 감동. 배경음악 분위기.
- [ ] **Q25. 시리즈 여부.** 단발인지, 시리즈면 예상 화수와 공통 오프닝 필요 여부.
- [ ] **Q26. 플랫폼.** 유튜브 쇼츠, 인스타 릴스, 틱톡 중 어디에 올릴지(자막 위치·세이프존이 달라짐).
