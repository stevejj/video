## 미결 질문 (번호 순서대로 하나씩 답해주세요)

답을 주시면 해당 줄에 `→ 답:` 으로 기록하고 체크합니다. 순서는 권장 순서일 뿐, 편한 것부터 답해도 됩니다.

### A. 캐릭터 (G1)

- [x] **Q1. 옷을 입나요?** → 답: 옷·액세서리·캐릭터 소품은 최대한 안 씀. 부득이 쓰게 되면 영상 생성에서 일관성이 보장되는지 사전 테스트로 확인한 뒤에만 허용. 어색한 영상은 절대 불가.
  - 원문 질문: 현재 시트는 알몸 펭귄입니다. 부부 일상(외출, 잠자리, 요리)을 그리려면 "옷 없음"으로 갈지, 최소 소품(앞치마, 목도리, 안경, 잠옷)만 쓸지, 아예 의상을 입힐지 정해야 합니다. 옷을 입히면 일관성 관리 대상이 두 배가 됩니다. 권장: 옷 없음 + 장면별 소품 1개 이내.
- [ ] **Q2. 키·체구 차이가 있나요?** 두 시트는 같은 체형입니다. 팽창수를 조금 크게 할지, 동일하게 갈지. 권장: 동일 체형(왜곡 위험 최소).
- [x] **Q3. 나이대와 성격.** → 답: 30대 초·중반 부부. 남편 팽창수 ESFJ, 아내 팽미순 ESTJ. 성격은 스토리 짤 때 참고용일 뿐 절대 기준 아님. 주제에 따라 바뀔 수 있음.
  - 원문 질문: 신혼인지 중년 부부인지, 각자 성격(예: 팽창수 느긋·덜렁, 팽미순 꼼꼼·잔소리). 행동 연출과 표정 설계의 기준입니다.
- [ ] **Q4. 팽창수의 볼터치.** 팽창수는 볼터치 없음으로 고정할까요? 시트에는 거의 없습니다. 권장: 없음(두 캐릭터 구분 요소로 사용).
- [ ] **Q5. 표정 범위.** 필요한 표정 목록을 정합니다. 제안: 기본 미소, 활짝 웃음, 놀람, 삐침/화남, 졸림, 슬픔(눈물). 이 중 쓸 것만 고르세요. 표정마다 참조 이미지를 만들어야 합니다.
- [ ] **Q6b. (쉽게 다시) 놀람·째려봄 표정에서 눈에 흰자가 보여도 되나요?** 두 캐릭터 표정 시트에서 그 두 칸에만 흰자가 생겼습니다. 허용하면 그대로 씀, 불허하면 그 두 칸만 재생성. 권장: 허용.
  - 원문: 팽창수 표정 시트의 놀람·째려봄 칸에 흰자가 생겼는데 플러시 스타일에서는 자연스러워 보임. 허용하면 규칙을 "기본 표정은 흰자 없음, 놀람·째려봄에만 소량 허용"으로 완화. 권장: 허용하되 영상 생성 시 놀람 컷은 부리 닫힘 유지.
- [ ] **Q6. (쉽게 다시) 영상에서 부리를 벌리게 할 건가요?** 말하거나 웃을 때 부리가 벌어지는 걸 허용할지, 항상 닫힌 채로 갈지. AI 영상에서 입 움직임은 얼굴 왜곡의 주범이라 권장은 '영상은 항상 닫힘, 대사는 자막'. 정지 이미지(표정 시트)의 벌어진 부리는 그대로 둠.
  - 원문: 말하는 장면에서 부리를 벌릴 건지, 항상 닫힌 미소로 갈지. AI 영상에서 부리 개폐는 왜곡 주요 원인입니다. 권장: 부리 닫힘 고정, 대사는 자막/나레이션.
- [x] **Q7. Google Flow에서 겪은 왜곡 사례.** → 답: 재활용 쓰레기 편. (A) 나가는데 도어락 비밀번호를 누름. (B) 양손에 쓰레기를 든 채 나가는 모션만 취하고 현관 안에서 걸어다님, 바깥으로 못 나감. → `03_현실감_규칙집.md` R1~R4로 규칙화.
  - 원문 질문: 구체적으로 무엇이 바뀌었나요? (얼굴형, 눈 크기, 색, 털 질감, 손발, 비율 등) 금지 항목에 반영합니다.
- [ ] **Q8. (쉽게 다시) 배경의 그림체.** 캐릭터는 봉제인형 털 질감인데, 집·가구·거리 같은 배경도 같은 봉제·미니어처 질감으로 그릴지, 아니면 배경은 일반 3D 애니메이션처럼 실제 재질(나무, 유리, 천)로 그릴지. Q37에서 '평범한 한국 아파트, 현실감'을 고르셨으니 권장은 '배경은 실제 재질, 캐릭터만 플러시'.
  - 원문: 현재 시트의 "봉제인형 플러시 3D 렌더" 질감을 그대로 유지할까요? 배경(집)도 같은 플러시/미니어처 디오라마 느낌으로 갈지, 배경은 일반 3D 애니메이션 느낌으로 갈지 정해야 합니다. 권장: 배경도 미니어처 디오라마 질감(캐릭터와 이질감 최소).
- [x] **Q9. 추가 참조 이미지 생성 승인.** → 답: 사용자가 Gemini에서 직접 생성. 프롬프트는 `docs/01a_추가참조이미지_프롬프트.md`. 모바일용 복사 도구: https://claude.ai/artifact/XYXEbtLVfEaLPaHofC12e6 (소스 `tools/prompter/index.html`). 결과물 업로드 대기 중.
  - 원문: 아래 "추가로 필요한 캐릭터 이미지" 목록을 Nano Banana로 만들 예정입니다. 이건 기획 자산이라 G6 이전에 생성해도 되는지 확인 바랍니다. (사용자가 직접 만들어 올려주셔도 됩니다.)
