# 팽창수 & 팽미순 부부일상 AI 영상 프로젝트

펭귄 부부 **팽창수**(머리 위 털뭉치)와 **팽미순**(분홍 볼터치)의 일상을 담은 AI 애니메이션 영상 프로젝트.

- 이미지 생성: Google Nano Banana (Gemini 이미지 API)
- 영상 생성: Kling AI (MCP)
- 원칙: **기획 문서가 전부 확정되기 전에는 이미지·영상 생성을 하지 않는다.**

## 폴더 구조

```
assets/characters/      캐릭터 참조 이미지 (원본, 워터마크 제거본, 각도별 크롭)
docs/00_진행현황.md      단계별 게이트, 완료/미완료, 미결 질문 목록  ← 항상 여기부터 확인
docs/01_캐릭터_바이블.md  외형 고정 항목, 금지 항목, 참조 이미지 목록
docs/02_공간_바이블.md    (예정) 공간별 평면 관계, 소품, 조명, 허용 앵글
docs/03_현실감_규칙집.md  (예정) 생활 상식, 동작 논리, 연속성 규칙
docs/04_에피소드_샷리스트.md (예정) 대본과 샷 단위 명세
docs/05_프롬프트_템플릿.md (예정) Nano Banana / Kling 프롬프트 템플릿
docs/06_검수_체크리스트.md (예정) 이미지·영상 통과 기준
tools/                  워터마크 제거 등 보조 스크립트
```

## 단계 게이트

| 단계 | 산출물 | 상태 |
|---|---|---|
| G0 캐릭터 자산 확보 | 원본 시트, 워터마크 제거, 각도별 크롭 | 완료 |
| G1 캐릭터 바이블 확정 | 01 문서 + 부족한 참조 이미지 보강 | 진행 중 |
| G2 공간 바이블 확정 | 02 문서 | 대기 |
| G3 현실감 규칙집 확정 | 03 문서 | 대기 |
| G4 에피소드 샷리스트 확정 | 04 문서 | 대기 |
| G5 프롬프트 템플릿·검수 기준 확정 | 05, 06 문서 | 대기 |
| G6 이미지 생성 (Nano Banana) | 샷별 시작/끝 프레임 | 잠김 |
| G7 영상 생성 (Kling) | 샷별 클립 | 잠김 |

G6, G7은 G1~G5가 모두 확정된 뒤에만 연다.
