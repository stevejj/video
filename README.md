# 팽창수 & 팽미순 부부일상 AI 영상 프로젝트

펭귄 부부 **팽창수**(머리 위 털뭉치)와 **팽미순**(분홍 볼터치)의 일상을 담은 AI 애니메이션 영상 프로젝트.

- 이미지 생성: Google Nano Banana API (한 장씩, 사용자 승인 후)
- 영상 생성: Kling AI (MCP)
- 원칙: **기획 문서가 전부 확정되기 전에는 이미지·영상 생성을 하지 않는다.**
